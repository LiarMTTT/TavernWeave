# Finish mode

Use Finish Mode when the implementation is mostly present but the final acceptance loop keeps expanding or losing focus.

Freeze one card:

```text
Visible problem:
Authority input:
Allowed files or surface:
Forbidden scope:
Direct checks:
Real acceptance object:
Single exit condition:
Next gate after exit:
```

Rules:

1. Work on one visible problem and one exit condition at a time.
2. New ideas go to follow-up notes; they do not widen the current slice.
3. Run the smallest check that can fail for this exact capability, then the required real gate.
4. Do not reimport, rebuild, or rewrite already accepted work unless the current problem depends on it.
5. Stop when the exit condition is proven. Do not spend remaining energy on adjacent cleanup.
6. Report what remains untested instead of lowering the acceptance definition.
