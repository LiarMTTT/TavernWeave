# Public-Derivative Boundary

This skill is a newly written public abstraction informed by private rolecard workshop runbooks and a local Gateway operations skill.

The public derivative intentionally omits all real infrastructure coordinates, domains, host aliases, absolute paths, secret filenames, client storage keys, repository-specific commands, card names, version-specific incidents, and production release details. Those remain in the private operational sources and are not required to use this generic method.
