# Provenance and Redistribution Boundary

This skill is a newly written, reduced-scope derivative informed by a local skill named `ui-styling`.

The local source carried inconsistent licensing signals: its frontmatter declared `MIT`, while its bundled `LICENSE.txt` contained the Apache License 2.0 and identified the author only as `claudekit`. That conflict was not resolved, so this derivative does not claim that the source was MIT-licensed or Apache-licensed.

To avoid carrying that ambiguity forward, this package does not copy the source skill's prose references, Python implementations, font files, coverage databases, tests, or generated artifacts. It restates the limited workflow in new text and points to primary public documentation for shadcn/ui, Radix UI, Tailwind CSS, and WAI-ARIA.

Any repository-level license applies only to the newly authored files in this derivative. It does not relicense third-party frameworks, components generated by their CLIs, or material from the unresolved local source. Preserve each dependency's own license and notices when redistributing generated or vendored code.
