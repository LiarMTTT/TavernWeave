# TavernWeave 插件执行合同

本合同在 TavernWeave 作为插件被调用，或任务运行于 dots 云端、连接的本机时生效。它只决定怎样识别宿主、选用工具、续接长任务和报告证据；具体工作仍由当前 Skill、用户授权、项目规则及原有验收门决定。普通本地独立 Skill 使用不必额外进入云端流程。

When this Skill runs through a plugin, cloud host, or remote machine, read [the plugin execution contract](plugin-runtime.md) at entry and apply its host, tool, and persistence checks before host-specific commands. Keep this Skill's scope, authorization, and acceptance gates.

## 先认清任务实际运行位置

1. 在任务入口确认当前是 dots 云端电脑、Codex 云端环境、已连接的用户电脑，还是其他本地宿主；再确认眼前实际提供的终端、Node/Python、Git、浏览器、应用连接和可写工作区。云端电脑有自己的文件与浏览器，本机连接是另一条访问路径；仅在本机可见的 Skill 需要实际连接并被当前任务加载。只按当前可见能力行动，不凭插件已安装推断某个工具、账号或目录可用。
2. `E:\...`、PowerShell、客户端全局 `AGENTS.md`/`CLAUDE.md`、本地安装和真实 SillyTavern，都是原文所述本机条件下的步骤。云端不能照搬本机绝对路径；项目文件和随包脚本只有在当前工作区实际存在且工具可运行时才可读写或执行。可用云端终端时使用该环境支持的命令，勿把命令示例当作宿主能力证明。
3. 没有终端或可写工作区时，仍可依据用户已提供的材料做文本分析、设计、审查与交接。将未运行的脚本、构建、浏览器动作和文件写入明确标为未验证；不声称已完成持久化。应用连接、登录态、权限与浏览器可达性逐项核对，不能由另一台电脑上的登录推断。

## 使用现有权限与资料

- 项目续接或拟写入时，先读当前项目已有的 `AGENTS.md`、`NEXT.md`、总设计、任务账本或等效唯一续接指针；只读实际存在且属于本次工作区的文件。已有状态源继续作为唯一权威，不为云端另造第二套进度文档。缺失时用本次对话中可核对的用户材料建立工作范围，并如实标记尚无持久续接文件。
- TavernWeave 随包库快照是公开资料。刷新快照需要原维护流程指定的私有源、allowlist 和检查，不能在云端凭空重建或从不明网页拼出缺失内容。用户作品、私有源、凭证、聊天记录及工作区文件只在已授权范围处理；不得因云端执行而写进公开插件、示例或发布包。
- 引导挡位与全局入口偏好持久化只适用于确有对应客户端配置、可预览目标且已获直接授权的本机适配流程。云端没有已核实的正式偏好存储能力时，仅按用户本任务的明确选择引导，说明没有保存；不推断、更改长期挡位，也不为了插件首次使用写全局规则。
- 已授权的独立工作继续按原范围推进。写入、联网、外部应用、付费调用、部署、发布、安装和真实宿主操作仍各守原有权限与验收门；插件或云端执行不自行扩大权限。

## 有界长任务与恢复

1. 开始前从用户目标和现有续接材料定下可检查的范围、预算或批次，以及完成、故障、预算耗尽、权限边界和需用户决定时的停止条件。工作量大时按原 Skill 的样本、批次和质量检查继续；不要因为预计耗时就中断已经授权且可以独立推进的部分。
2. 每个阶段在实际可持久的项目工作区更新真实产物、来源/输入版本、已运行的验证、未验证项和下一步；保留原项目的唯一续接指针。若当前只有对话可保存，就用消息交接并明确文件状态未持久化。文件存在不等于云端任务已加载，也不等于真实酒馆、设备或人工验收通过。
3. 任务恢复后重读产物与续接证据，核对源版本、未完成批次和上次外部操作的实际结果，再决定重试，避免重复写入、发送、付款或部署。对于无法查证的外部结果，报告不确定性并停在相应执行门。
4. dots 的云端持续运行、任务调度与关机后可用性由平台及当前连接条件提供；插件本身不安装常驻服务器、定时器或后台进程，也不新增收费服务。不要许诺账户套餐、执行时长或工具一定可用。只能按已观察到的平台能力报告继续运行状态。

交付时分别报告：源码或文本产物、自动检查、云端/浏览器观察、真实 SillyTavern 或设备验证、人工接受、Git 与发布状态。一个层级的证据不能替代另一个；按原 Skill 给出下一道门。

官方依据：[OpenAI 插件打包说明](https://developers.openai.com/plugins/build/plugins)；[dots 云端电脑与应用连接说明](https://learn.chatgpt.com/docs/dots/computers-and-apps)。这里的操作规则是 TavernWeave 对这些宿主边界的实现约定，实际能力以当前任务观察为准。
