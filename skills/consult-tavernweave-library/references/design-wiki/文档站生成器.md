# 文档站生成器

本页**不是已采用文档栈**，也不是工坊必须换主题的工单。检索时间：2026-08-14。账本枢纽是 [[queries/第二批蒸馏目标]] **B2-Docs**（约 12 条），加厚见 [[10-收件箱/写回候选/第四批-B4-Docs]]。写法框架见 [[queries/第三批蒸馏目标]] **B3-Diataxis**；11ty / Hugo / MDX 只回 **B3-SSG**，本页不展开。

## 一句话定义

文档站生成器是把 Markdown / MDX 等源文件变成可浏览文档站点的**软件**（主题、路由、构建）。它不管「四种文档怎么写」。写法框架另走 Diátaxis / Write the Docs；**软件 MIT ≠ 正文许可**。

## 为什么重要

独立文档站常被并成「装一个开源主题」。三件事不是一层：站点怎么建、四种文档怎么分、正文能不能改写再发布。生成器 MIT 只管这份软件，不管你贴进去的手册；Diátaxis 是 CC BY-SA，Write the Docs 带 NC。选错入口会把镜像当枢纽，或把 Insiders 功能表整份标 MIT。

[[concepts/前端架构名词与取舍]] 正例写过「文档站 SSG + 搜索岛」；[[comparisons/工坊架构该上与不该上]] 把独立站默认写成 SSG/ISR + islands。那是架构映射，**不是**本仓库已采用 Starlight / VitePress。

## 如何运作

### 生成器 ≠ 写法框架

| 层 | 解决什么 | 本页对象 |
|---|---|---|
| 站点怎么建 | 源文件 → HTML、主题、路由 | Starlight / VitePress / Docusaurus / Material / Nextra / Fumadocs |
| 四种文档怎么分 | 教程 / 操作指南 / 参考 / 解释 | Diátaxis（`diataxis.fr`） |
| 社区写法入门 | README、安装、许可声明、少用 FAQ 当正文 | Write the Docs |

用 Starlight 或 VitePress **托管**文档，不会把你复制进去的 Diátaxis 段落改成 MIT。四类目录也不是某主题的内置功能。

### 本波核过的两套 MIT 软件

**Starlight** 是 Astro 上的文档主题，不是独立语言。新建用 `npm create astro@latest -- --template starlight`；本地 `npm run dev`；新页放 `src/content/docs/`，并点到 Pages 指南的 MDX / Markdoc。升级走 `npx @astrojs/upgrade`。LICENSE 是 MIT（Copyright 2023 Astro contributors）。

**VitePress** 官方入门写明：Node.js **22+**；包是 ESM-only，近处 `package.json` 要 `"type": "module"`。现网安装是 `npm add -D vitepress@next`，再 `npx vitepress init`。配置在 `.vitepress/config.js`；Markdown 在该目录外，按文件路由出 HTML。要改默认主题或用 Vue API，须把 `vue` 装成依赖。LICENSE 是 MIT（Copyright 2019-present Yuxi (Evan) You）。它坐在 Vite 上，默认压缩/转译见 [[concepts/构建链与Vite]]，本页不重蒸。不要写成「稳版 1.x 已钉」。

### 本波未打开入门的三套

Docusaurus、Material for MkDocs 入门、Nextra：**本波未打开入门页**，不假装读完全文。只留 B2 枢纽与公开许可事实：Docusaurus 软件常标 MIT，仓内 `LICENSE-docs` 是 CC BY 4.0，不要只写「Docusaurus 是 MIT」；Material 公开主题 MIT，Insiders 是付费私仓，功能表不能整份标 MIT；Nextra 是 Next.js 文档主题。

**Fumadocs** 真源是 `fumadocs.dev`（`npm create fumadocs-app`，Node 22）。检索会撞到 `mintlify.com/fuma-nama/fumadocs`，那是镜像，不当枢纽。

### 写法层：两套不可混的 Creative Commons

Diátaxis `start-here` 把文档分成四类：教程（学习、在场指导）、操作指南（已胜任者的真实任务）、参考（中性事实）、解释（背景与为什么）。作者写你可以只用其中一点，没有考试。仓内 `LICENSE.rst` 与 README 都是 **CC BY-SA 4.0**。colophon：现站 Sphinx + Furo，挂 Read the Docs；引用指向 `diataxis.fr`；前身是 Divio 时期的 `documentation.divio.com`，作者说多数仍同意、若干处已改口。

Write the Docs 入门指南讲 README、安装、许可声明、少用 FAQ 当正文。页脚徽章与 `www` 仓 `LICENSE.md` 均为 **CC BY-NC-SA 4.0**。社区 Slack 有 `#diataxis` 频道，这是邻接，不是同一许可。带 NC 的正文不能和 Diátaxis 的 BY-SA 合成一份衍生手册。

### 许可三档（必须分开）

| 对象 | 管什么 | SPDX / 许可证 | 改编条件 |
|---|---|---|---|
| Starlight / VitePress 等生成器软件 | 主题与构建**软件** | 常见 MIT（各仓各记） | 保留版权声明即可；不管站点正文 |
| Diátaxis | 文档**写法**正文 | CC BY-SA 4.0 | 署名 + **ShareAlike** |
| Write the Docs | 社区指南正文 | CC BY-NC-SA 4.0 | 署名 + **NC** + SA |

Docusaurus 还要再拆一层：软件 MIT ≠ 文档 CC BY 4.0。

### 搜索、SSG、测试不在本页

站内搜索（Pagefind / DocSearch 等）见 [[concepts/站内搜索与Pagefind]]。11ty / Hugo / MDX 见 [[queries/第三批蒸馏目标]] B3-SSG（Zola 是 EUPL-1.2，不是 MIT）。文档站截图回归见 [[concepts/测试与视觉回归]]。本页不升新条。

## 必须保留的冲突

- Starlight MIT ≠ VitePress MIT ≠ Diátaxis CC BY-SA。前两份同 SPDX 也要分条，第三份不是软件许可。
- Write the Docs **带 NC**；Diátaxis **不带 NC、带 SA**。不可合成一份衍生手册。
- Docusaurus：软件 MIT 与文档 CC BY 4.0 是两份文件。不要只写「Docusaurus 是 MIT」。
- Material for MkDocs：公开主题 MIT；Insiders 另购，功能表不能整份标 MIT。
- VitePress 官方入门现网装的是 `vitepress@next`，并写 Node 22+、ESM-only。不要写成「稳版 1.x 已钉」。
- Fumadocs 真源是 `fumadocs.dev`。`mintlify.com/fuma-nama/fumadocs` 是镜像，不当枢纽。
- Diátaxis 现站 ≠ Divio 旧稿。引用以 `diataxis.fr` 为准。
- 生成器解决**站点怎么建**；Diátaxis 解决**四种文档怎么分**。不要把四类目录写成某主题的内置功能。
- 11ty / Hugo / MDX 已在 B3-SSG；本页不重收。
- 站内搜索已在 [[concepts/站内搜索与Pagefind]]。本页不升新条。
- 「文档站 SSG + 搜索岛」是架构映射，**不是**本仓库已采用某生成器。
- Docusaurus / Nextra / Material 入门本波未打开，不把枢纽 URL 写成「已读完全文」。

## 例子

- 正例：用 Starlight 或 VitePress 建独立文档站；贴进站里的第三方手册另核许可。
- 正例：写法层只引 `diataxis.fr` 与 `LICENSE.rst`；不把 Write the Docs 段落并进同一份衍生手册。
- 正例：Material 公开主题按 MIT 记；Insiders 功能单独标付费，不写进 MIT 表。
- 正例：Fumadocs 以 `fumadocs.dev` 为准，不引用 mintlify 镜像当枢纽。
- 反例：把六套生成器 + Diátaxis + Write the Docs 并成「都是开源文档方案」。
- 反例：把教程 / 操作指南 / 参考 / 解释写成 Starlight 或 VitePress 的内置功能。
- 反例：把 Docusaurus / Nextra 入门写成「本波已读」，或把本页写成「工坊已采用某主题」。

## 边界与易混概念

- 不包括：Mintlify / GitBook 报价、选题落地、成品皮肤、卡 JSON/PNG、凭证、11ty / Hugo / MDX 展开、Pagefind 逐步命令、API 风格指南（回 B3-APIsty）。
- 文档站生成器 ≠ [[concepts/概念分级]] 的 L3「滑块 / Demo 生成器」。本页只谈文档站点软件。
- 软件 MIT ≠ 站点正文许可。生成器许可不覆盖你粘贴的手册。
- VitePress ≠ Vite 整条构建链。默认压缩 / 转译回 [[concepts/构建链与Vite]]。
- 搜索岛 ≠ 生成器。索引合同回 [[concepts/站内搜索与Pagefind]]。
- 易混：听到「开源文档方案」就以为软件许可、写法正文、社区指南是同一份 SPDX。
