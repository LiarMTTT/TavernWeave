# 媒体库路径

稳定卡的头像/立绘不走 Live2D（E4 未走），也不走宿主表情扩展当主链。卡内 `media_library.js` 管图：分类、槽、变体、来源、气泡里怎么用。

## 星月 4.0.0 / 交错同族

脚本 id 仍叫 `crossed-zone-media-library`（同源组件）。

| 轴 | 值 |
|---|---|
| 类型 `ASSET_TYPES` | `bond` / `mecha` / `mothership` / `self` / `scene` |
| 槽 `ASSET_SLOTS` | `avatar`（头像）/ `portrait`（立绘） |
| 羁绊变体 | `normal` / `nude` / `aftermath` |
| 来源 | 内置 catalog、`data-url`、`url-external` |

4.0.0 存档上限 48M 字符；保存时剥离内置资产回声，只留玩家自己的图。GIF ≤ 3M，单张 data URL ≤ 4M。头像最长边 256，立绘 1200。

内置图用 `xy-builtin-media-assets` 段和 revision 号。本 Wiki 不搬 data URL。

## 谁在读它

- 对话气泡：`data-xy-dialog-avatar` → `resolveDialogMedia`
- 开局页 / 控制中心：`data-xy-media-manager-*` 面板
- 交错状态栏：`data-cz-media-*` 临时切变体、打开设置
- OMNI 挂载：同一文件里的 `renderOmniMounts`（媒体库兼当楼内挂载器）

## 边界

- E3 音频/多模态、E4 Live2D：三张稳定卡主路径未走。
- 外链 `url-external` 是玩家资源，不当作 AFV 真源，也不写进 raw。
- 工坊发布身份模板时要提示不可移植的本地媒体 key。
