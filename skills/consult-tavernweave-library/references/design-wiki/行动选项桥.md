# 行动选项桥

模型在正文里给选项，正则先铺容器，桥把原文变成按钮。点一下：默认换行填进 ST 输入框（可多选再改），勾了直发就立刻发送并触发生成。

## 星月 4.0.0

文件：`options_bridge.js`（卡内自包含，不依赖远程 runtime）。

```text
正则「行动选项渲染」→ data-xyopt-root
  → 桥扫最新楼的 root
  → 解析 data-xyopt-raw
  → 往 data-xyopt-list 填 data-xyopt-choice 按钮
  → 点击：填输入框 或 直发
```

旧楼被「旧楼选项隐藏」正则清空，桥不服务历史楼。直发/折叠偏好在 `localStorage`。

找宿主：和其它桥一样向上爬 `parent`，所有输入框操作走 `hostDocument`。

Runtime key `__xyOptionsBridgeRuntime`，替换前先 destroy。

## 怪谈 1.0.9

`data-kdnopt-*` 与 `data-xyopt-*` 同构。同一套直发/折叠/提示。开局表单是另一组 `data-kdnopen-*`，不要和选项桥混成一个根。

结算卡 `data-kdn-settlement` 是展示 MVU 分析/补丁，不是选项按钮。

## DOM 协议

见 [[concepts/角色卡DOM与挂载点]] 的 `data-xyopt-*` 表。样式选择器全是属性选择器；根上 `container-type: inline-size`，窄了单列。

## 边界

- 桥不写 MVU。选项只影响输入框和生成触发。
- 不要在控制中心再做一套平行选项解析。
- 交错状态栏里的 `data-batch-*` / 加点按钮是 HUD 内动作，不是楼内行动选项。
