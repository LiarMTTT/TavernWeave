# 消息渲染与正则管线

模型吐出的是文本。玩家看见的楼，是 ST 宏 → 正则 → Markdown → DOMPurify → `.mes_text`。卡要插 UI，只能接到这条管线上，不能假装自己是另一张网页。指南：`A5_渲染管线与宏.md`、`A6_正则机制.md`。

## 管线（A5 对 v1.14.0 `messageFormatting` 的直读）

```text
LLM 原文
  → 剥 prompt-bias
  → 正则（placement = AI_OUTPUT 且 markdownOnly 时，这一步就跑）
  → encode_tags / 引号处理
  → Markdown（Showdown）
  → 净化
  → 写入 .mes_text
```

宏求值在更前面。自定义 XML 标签 + 换行有历史坑（A5 §8.2）。指南曾推断 DOMPurify 会剥内联 `style`；生产 OMNI 靠内联且真机能看，AFV 按误报处理，细则见 [[concepts/OMNI正则与data属性选择器]]。

## 正则脚本存在哪

| 类型 | 位置 | 稳定卡 |
|---|---|---|
| SCOPED | 卡 `data.extensions.regex_scripts` | 主用 |
| GLOBAL | `settings.json` | 不依赖 |
| PRESET | API 预设 | 不锁 |

执行顺序：Global → Scoped → Preset，链式，上一条输出是下一条输入。`A6` 订正过旧草稿的顺序。

关键字段：`findRegex`、`replaceString`（`$1` / `{{match}}`）、`placement`、`markdownOnly`、`promptOnly`、`minDepth` / `maxDepth`。

显示美化：`markdownOnly: true`，`promptOnly: false`。框出现在聊天里 ≠ 进模型上下文。

## 稳定卡接到哪几截

| 目的 | 星月 4.0.0 组件 | 替换结果 |
|---|---|---|
| 变量同步完成 | `update_variable_omni_done_regex.html` | `data-xy-omni="done"` 挂载点 |
| 预分析 / 进度 | 组件库 OMNI 模块；进度版曾因吞正文删过 | `data-xy-omni="analysis"` / `progress` |
| 对话气泡 | `dialog_bubble_regex.html` | `data-xy-dialog-render` + 隐藏 textarea |
| CoT 对话 | `dialog_cot_bubble_regex.html` | `data-xy-cot-dialog-render` |
| 行动选项 | `options_render_regex.html` | `data-xyopt-root` |
| 开局远程壳 | `opening_expand_regex.html` | `data-xy-opening-remote` |
| 开局 prompt 剥离 | `opening_prompt_strip_regex.html` | 不让大 HTML 进上下文 |
| 状态栏 | 星月后期是薄壳；交错是整页 `status_bar_regex.html` | ` ```html ` 代码块 → TH iframe |

TH 看见消息里的 ` ```html ` 代码块，就渲成 iframe（`srcdoc` = 块内容）。这是状态栏的容器，不是普通 Markdown。

## 和 JS 桥怎么接

正则只负责**占位**。真正画按钮、拉远程模板、填输入框的是：

- `media_library.js`：扫 `[data-xy-omni]`、气泡
- `options_bridge.js`：扫 `[data-xyopt-root]`
- 控制中心：开局远程、OMNI 按钮

旧楼选项会被另一条「旧楼选项隐藏」正则清掉，桥只服务最新楼。见 [[concepts/行动选项桥]]。

## 避坑（卡侧已焊）

- 消息楼选择器走 `data-*`。ST 给 class 加 `custom-`。
- 预分析禁止裸 `[\s\S]*?` 跨同名标签。
- `findRegex` 空字符串等于不执行。
- 不要用正则写变量。写变量是 MVU 的事。
