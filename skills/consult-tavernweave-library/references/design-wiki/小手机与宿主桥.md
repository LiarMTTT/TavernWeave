# 小手机与宿主桥

小手机不是消息楼里的一块正则 HTML。它是挂在 **SillyTavern 宿主 `document.body`** 上的单例抽屉，自己读 MVU、自己跟输入框说话。怪谈 1.0.9 是这条路的真源；星月 4.0.0 从怪谈 1.0.8 骨架移植并改名。

## 职责（`kdn_bridge.js` 文件头）

1. HUD HTML 内嵌在脚本里，不读角色卡 `extensions.*.hud_html`。
2. 抽屉单例挂宿主 body，不依赖消息楼，也不等 `<UpdateVariable>` 才出现。
3. 提供 MVU 快照、事件委托、发送/填入桥；变量或消息变了就刷新。

星月对应物：`phone-bridge` 懒加载进控制中心，根节点 `#xy-phone-root` / `data-xyph-hud-root`。桥名 `__xyPhoneSend`、`__xyPhoneInput`、`__xyPhoneStat` 等。

## 宿主怎么找

```text
当前 window
  → 最多向上 parent 4 层
  → 能摸到 parent.document.body 就继续
  → 得到 hostWindow / hostDocument
```

热重载先 `previous.destroy('replace')`，再挂新 runtime。key：怪谈 `__kdnHudRuntime` / `__kdnBridgeRuntime`；星月 `__xyPhoneBridgeRuntime`。

## 和消息楼 HUD 的差别

| | 小手机 | 正则状态栏 |
|---|---|---|
| 挂哪 | 宿主 body | 消息 iframe / blob |
| 几份 | 单例 | 每楼可能一份，要去重 |
| 变量 | 提交去抖后的快照 | 当前楼 `getVariables` / `Mvu.getMvuData` |
| 皮肤 | `data-kdn-shell` / `data-kdn-charm` | 卡内 CSS |

移动端抽屉外壳（安全区、软键盘、`visualViewport`）见 C12 和 [[concepts/入口外壳与HUD宿主]]。小手机可以是抽屉里的内容，也可以自己就是那只抽屉。

## 怪谈多写一口

写下规则时三写：MVU 变量、世界书动态条目、玩家行动消息。桥是白名单，不是把整个 `stat_data` 暴露给 HUD 乱写。

## 边界

- 不要把小手机再塞进 `first_mes`。
- 不要和 git-mount 状态栏抢同一套 `injectBridge` 假设：小手机在宿主页，TH 全局通常在。
- 末日之后设计档的 `control-shell.js` / 11 根只读是未出生方案，名词可对照，不当稳定发卡。
