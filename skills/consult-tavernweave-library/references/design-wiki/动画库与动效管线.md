# 动画库与动效管线

动效先分两层：浏览器自己会的（CSS / Web Animations / View Transitions / 滚动驱动），和库在上面补的（时间轴、弹簧、手势、矢量运行时）。本页是行业蒸馏，不按「角色卡能不能用」删名词。许可以各站原文为准，落地前再核一次。灵感入口账本见 [[queries/前端视觉与灵感站点蒸馏目标]]。视觉层叠与玻璃见 [[concepts/视觉CSS与设计token]]。

B2-Anim-15 / B2-VT / B2-Scroll-12 与第一批 WAAPI、View Transitions、scroll-driven 是同文重叠，不是新 API。本页只补默认缓动、同文档/跨文档基线和第二波库。

## 一句话定义

动效管线决定「谁在改哪些属性、按什么曲线、能不能打断、用户能不能关掉」。库是这条管线上的加速器，不是替代浏览器合同。

## 为什么重要

同一套「按钮弹一下 / 抽屉滑上来 / 页面转场 / 机甲准星呼吸」可以只写 CSS，也可以上时间轴库或矢量运行时。选错的代价是包体积、许可、主线程卡顿，以及忽略 `prefers-reduced-motion`。

## 平台层（先认浏览器）

| 名词 | 管什么 | 优点 | 缺点 | 来源 |
|---|---|---|---|---|
| CSS Transitions | 属性从 A 变到 B | 零依赖、合成层友好 | 编排弱；打断和交错要自己写 | [MDN transitions](https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_transitions) |
| CSS Animations | `@keyframes` 多段 | 声明式、可循环 | 和 JS 状态同步笨；不能轻易弹簧 | [MDN animations](https://developer.mozilla.org/en-US/docs/Web/CSS/CSS_animations) |
| Web Animations API | JS 控制同一套动画引擎 | 可暂停/反转/时间线；Motion 也走这条 | 要写 JS；旧环境要垫 | [MDN WAAPI](https://developer.mozilla.org/en-US/docs/Web/API/Web_Animations_API) |
| View Transitions | 两态之间的快照转场 | 原生跨 DOM 更新的过渡 | **同文档**已是 Baseline Newly（Firefox 144）；**跨文档**仍 Limited | [MDN View Transition](https://developer.mozilla.org/en-US/docs/Web/API/View_Transition_API)；[web.dev 同文档 Baseline](https://web.dev/blog/same-document-view-transitions-are-now-baseline-newly-available) |
| Scroll-driven | 动画进度绑滚动 | 少写 IntersectionObserver | 新特性；兼容要查 Can I use | [MDN scroll-driven](https://developer.mozilla.org/en-US/docs/Web/CSS/Guides/Scroll-driven_animations) |
| `prefers-reduced-motion` | 用户要少动 | 合规底线 | 只声明偏好，库不会自动替你关完 | [MDN](https://developer.mozilla.org/en-US/docs/Web/CSS/@media/prefers-reduced-motion)；[WCAG](https://www.w3.org/WAI/standards-guidelines/wcag/) |

缓动本身不是库。[easings.net](https://easings.net/) 给常见曲线的公式和可视化；[cubic-bezier.com](https://cubic-bezier.com/) 调 `cubic-bezier()`。CSS `easing-function` 能表达的，不必为一条曲线引入 JS。

[CSS Easing 2](https://www.w3.org/TR/css-easing-2/) **没有**原生 `spring()`。bounce / spring 要用 [`linear()`](https://developer.chrome.com/docs/css-ui/css-linear-easing-function) 多点折线逼近，这是预计算曲线，不是运行时弹簧。真弹簧仍走 JS（Motion / GSAP）。

同一引擎默认缓动不同：CSS `animation` 默认 `ease`；WAAPI `element.animate()` 默认 `linear`。CSS 的 timing-function 作用在每一对 keyframe 之间；WAAPI options 上的 `easing` 作用在整段 effect。

## JS / 框架库

| 库 | 何时用 | 优点 | 缺点 / 许可 | 来源 |
|---|---|---|---|---|
| [GSAP](https://gsap.com/) | 跨框架时间轴、滚动、字符/路径、要精确编排 | 时间轴强；插件面大；Demo Hub 可点 | 包比一段 CSS 重。2025-04-30 起 Standard No Charge：网站/应用商用免费；**禁止**做成和 Webflow 抢生意的「无代码可视化动画构建器」 | [Standard License](https://gsap.com/community/standard-license/)；[Webflow 公告](https://webflow.com/blog/gsap-becomes-free)；[Eases](https://gsap.com/docs/v3/Eases/)；[Demo Hub](https://demos.gsap.com/) |
| [Motion](https://motion.dev/)（原 Framer Motion） | React / JS / Vue 里声明式 UI 动效、手势、布局动画 | 简单情况走 WAAPI/ScrollTimeline；弹簧、打断、手势再回 JS。核心 MIT | 和 React 最贴；纯 HTML 要改写。Motion+ 是一次性付费的示例/高级 API/AI Kit，不是核心库门票 | [React 入门](https://motion.dev/docs/react-quick-start)；[Examples](https://motion.dev/examples)；[Motion+](https://motion.dev/plus) |
| [Anime.js](https://animejs.com/) | 要轻量 JS 时间轴、不绑 React | API 面小、好上手 | 生态和插件不如 GSAP 深 | 官网 |
| [Lottie](https://airbnb.github.io/lottie/#/) | 设计师从 After Effects 出 JSON，运行时播矢量 | 设计/开发交接清楚 | 运行时 + JSON 体积；复杂 AE 特性会丢；要独立播放器 | Airbnb Lottie 文档 |
| [Rive](https://rive.app/) | 状态机驱动的交互矢量（按钮、角色、HUD 仪表） | 编辑器里编状态，运行时听输入 | 运行时 MIT；**导出上生产要付费**（2025-10-20 起 Cadet 起才无限导出） | [rive.app](https://rive.app/)；[导出说明](https://rive.app/docs/editor/exporting/exporting-for-runtime) |

### 第二波库（Theatre / 滚动 / 3D 运行时）

全部 candidate，不是已采用。

| 库 | 何时看 | 许可 / 坑 | 来源 |
|---|---|---|---|
| [Theatre.js](https://www.theatrejs.com/docs/latest) | 浏览器里用时间轴编 3D/UI | `@theatre/core` Apache-2.0；`@theatre/studio` AGPL-3.0，生产包不应打进 studio | [GitHub](https://github.com/theatre-js/theatre) |
| [Lenis](https://github.com/darkroomengineering/lenis) | 平滑滚动且尽量走原生滚动条 | MIT | 仓 |
| [Locomotive Scroll v5](https://scroll.locomotive.ca/docs/) | 在 Lenis 上加视口检测 / 视差 | v5 引擎是 Lenis；不要把 v4 当现行合同 | 官方 docs |
| Spline runtime | 嵌入 Spline 场景 | **无 SPDX**；`@splinetool/react-spline` 是 MIT，runtime 没有 LICENSE | npm / [issue 234](https://github.com/splinetool/react-spline/issues/234) |
| [Unicorn Studio](https://www.unicorn.studio/docs/pricing/) | 无代码 WebGL 场景 | 运行时专有；导出上生产要付费 | 定价页 |

GSAP 旧口径「Club 插件要付费 / 商用另买」以 2025-04-30 为准作废。本页按 Standard License 与 Webflow 公告写。禁止用途只覆盖「无代码可视化动画构建器」这类竞争产品，不覆盖普通网站或应用里的动效。

Motion 自己写：简单 hover/颜色用 CSS 更轻；要和 React state、手势、layout 绑定再上库。核心开源 MIT；付费的是 Motion+ 的示例源码和高级件，买完按他们的条款用于项目，不能把 Plus 源码再打包成竞品库。

## 生成器与过时件

| 入口 | 角色 | 注意 |
|---|---|---|
| [Animista](https://animista.net/) | 调 `@keyframes`，带走用到的那几条 | 不要把整站生成物当设计系统 |
| [Hover.css](https://ianlunn.github.io/Hover/) | 2010 年代 hover 类名集 | 过时；新活优先 CSS transition 或平台 API |
| GSAP Demo Hub / Motion Examples | 看手感、抄编排思路 | Demo ≠ 已采用皮肤；Motion 部分示例在 Plus 墙后 |

## 怎么选（行业，不是卡规）

```text
只要属性 A→B、可声明
  → CSS transition / animation
要 JS 控制同一条动画（暂停、进度、编排）且不想上库
  → Web Animations API
跨文档/跨树的页面转场
  → View Transitions（不够再补库）
进度必须跟滚动走
  → CSS scroll-driven；不够再 GSAP ScrollTrigger / Motion useScroll
React 里手势 + layout + 进出场
  → Motion
跨框架、长时间轴、路径/字符
  → GSAP
设计师交 AE / 状态机矢量
  → Lottie 或 Rive
```

无论哪条：先接 `prefers-reduced-motion`。大位移、循环闪烁、自动播放要可关。WCAG 不因用了某库而豁免。

## 例子

- 正例：按钮 hover 用 CSS transition；列表进出用 WAAPI 或 Motion；长滚动叙事用 GSAP 时间轴。
- 正例：核过 GSAP Standard License 后，商用站点直接用含原 Club 插件的标准包。
- 反例：为一条 `opacity` 渐变引入 GSAP + ScrollTrigger。
- 反例：把 Motion+ 示例源码再发行成自己的组件库去卖。
- 反例：忽略 `prefers-reduced-motion`，让准星和扫描线一直闪。

## 边界与易混概念

- 本页不是「本仓库已采用 GSAP/Motion」的声明。
- CSS 动画和 WAAPI 是同一引擎的两种入口，不是两套互斥世界观。
- GSAP「已免费」≠ 无条款；竞争 Webflow 的可视化构建器仍禁止。
- Motion 核心免费 ≠ Motion+ 示例免费。
- Lottie 不是通用 JS 动画库，是播放预烘焙矢量。
- CSS 无原生 `spring()`；`linear()` 取样 ≠ 运行时弹簧。
- View Transitions：同文档 Baseline Newly，跨文档 Limited。不要写「已经 Baseline」而不加「同文档」。
- Theatre studio 是 AGPL；Spline runtime 无 SPDX；Unicorn / Rive 导出上生产要付费。
- iframe 里的动画仍相对该框的文档和视口；`1vh`、跨文档 `backdrop-filter` 见 [[concepts/视觉CSS与设计token]]、[[comparisons/嵌入三路径对照]]。

## 映射到本仓库

角色卡 HUD 能用平台 CSS / WAAPI，也能嵌 GSAP 或 Motion——本页不因为「卡」就删库。约束是包体积、许可、以及动效不要穿透宿主消息楼的净化规则。工坊站和独立站点按上面的「怎么选」。产品级「工坊该不该上 SPA」见 [[comparisons/工坊架构该上与不该上]]，不要和本页的库清单混成一句「所以都不要」。
