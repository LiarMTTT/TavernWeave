# 控制中心与状态栏

## 一句话定义

控制中心是卡内功能容器与设置/写入入口；状态栏是前台 HUD，负责读变量、分页展示和重交互，不承担控制中心那类脚本入口职责。

## 为什么重要

同源三卡的玩家能看见的「前端」主要就是这两块，外加开局页。重交互（制造、地图）放 HUD tab，不塞进控制中心。

## 如何运作

### 控制中心 Control Center

英文标识常见 `control_center.js`。交错宙域脚本 id 为 `crossed-zone-control-center`。入口只用 Tavern Helper 脚本按钮 API（魔棒下级菜单），不在输入框上方插 DOM。交错按钮名是 `交错宙域控制中心`，监听必须 `getButtonEvent('交错宙域控制中心')`。星月控制中心 ScriptTree 上没有按钮，改挂 `#extensionsMenu`；ST 切聊天会拆掉顶栏，要订 `CHAT_CHANGED`，延时约 250ms 再 `ensureWandEntry()`。

热重载：脚本顶先 `previous.destroy()`，再挂新 runtime，否则监听叠加。

它负责：HUD 设置持久化、媒体 I/O、OMNI 预设、创意工坊加载时序、世界书管理器的 handler。面板 head 可拖动，限制在可视范围。

星月 4.0.0：创意工坊安全契约随控制中心内嵌；必须等契约验证完成再加载工坊运行时。见 [[concepts/创意工坊与安全契约]]。

### 状态栏 Status Bar / HUD

显示层常见输出名 `status_bar_regex.html`。后期星月改为卡内薄壳 + git-mount 真身：壳约 4KB，真身 `status-bar.html` 放 runtime，push 即可热修。

壳与真身不在同一 window。Tavern Helper 的 `$` / `Mvu` / `eventOn` 不会自动进 blob iframe。`injectBridge` 给真身补 jQuery/lodash 与顶层 MVU 桥，否则 `readCurrentHudVariables` 静默返回空、界面全是 `--`。

`window.XY_RT_BASE` 本应把 runtime 基址从控制中心传给状态栏壳；实测 CC 的 script-iframe 与状态栏 message-iframe 隔离，壳往往走内联 `BASE` / `BASE_CF`。出卡时必须改对版本段。

## 例子

- 正例：交错宙域 Tab 切换先激活目标容器再强制渲染，避免 `renderedTabSignatures` 命中后停在上一页。
- 反例：仿真壳不复现「壳→blob→真身」三层链，仿真绿、真机红。

## 边界与易混概念

- 控制中心不是状态栏，也不是开局页。开局页是 `first_message_opening.html`，死守 first_mes 不塞大 HTML。
- 状态栏远程挂载壳与全量本地版互斥，同名输出 `status_bar_regex.html`，二选一。
- OMNI 美化是消息楼显示层，由 `media_library.js` 的 `renderOmniMounts` 挂载，按钮再交给控制中心 `handleOmniButton`。
