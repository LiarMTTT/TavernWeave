# 中文设计系统

本页不是已采用皮肤，也不是成品中后台，也不是工坊必须改用四家之一的工单。检索时间：2026-08-14。只谈四家官方中文规范入口与 token / 暗色合同。账本枢纽是 [[queries/第二批蒸馏目标]] 的 **B2-ZH**。

## 一句话定义

中文设计系统在本页只指四家**自己用中文发布规范**的企业级体系：Ant Design、TDesign、Arco Design、Semi Design。每家是设计语言 + token + 带皮肤组件库，不是「给中文排印用的系统」，也不是 Material / HIG / Fluent 的民间译本。

## 为什么重要

中后台控件、色板、暗色和主题定制，国内产品常从这四家抄合同。先认清：谁是官方宿主、谁只是社区实现、token 怎么派生、暗色靠算法还是 CSS 变量。抄错宿主或把四家并成一套「中文 Ant」，后面的皮肤和 iframe 映射都会歪。

## 如何运作

### 四家并列，不是一个「中文 Ant」

| 家族 | 谁维护 | 官方实现 | 价值观原话 |
|---|---|---|---|
| Ant | 蚂蚁集团体验技术部 | React（`antd`） | 自然 / 确定性 / 意义感 / 生长性 |
| TDesign | 腾讯开源协同 | Vue2 / Vue3 / React 桌面与小程序等为 LTS；移动 React、Flutter、Uniapp 为 Alpha | 包容 / 多元 / 进化 / 连接 |
| Arco | 字节 GIP UED + 基础架构前端 | React 官方库；Vue 是官方生态另一套 | 务实的浪漫主义 |
| Semi | 抖音前端 + MED | 只实现了 React Adapter | 优质默认（不变）+ 开放定制（多变） |

Ant [介绍](https://ant.design/docs/spec/introduce-cn) 把 [Ant Design of Vue](http://antdv.com) 标成**社区实现**。TDesign 的 Vue 是官方仓库。不要用「Vue 也能用」把两家实现合同并成一条。

Arco 与 Semi 都来自字节，**不是同一套系统**。Arco 文头写「基于 Byte Design 升级」；Semi 从抖音 / 剪映 / 飞书等业务抽默认，再用 DSM 出品牌主题。飞书 Universe Design 是 Semi 的示例主题，不是第五家入口。

### Design Token：同名不同合同

四家都说 Design Token，派生和载体不一样，也都不等于 [[concepts/视觉CSS与设计token]] 里的 DTCG JSON。

- **Ant（5.0+）**：`ConfigProvider.theme`。Seed → Map → Alias 三层派生；多数情况改 Seed 即可。预设算法：`defaultAlgorithm` / `darkAlgorithm` / `compactAlgorithm`。可嵌套局部主题。`useToken` / `getDesignToken` 读当前值。静态 `message` / `Modal.xxx` / `notification` **吃不到** ConfigProvider。6.0 起 `zeroRuntime` 不再运行时生成样式，要自己引 CSS。站点检索日侧栏见 changelog **v6.6.0**。
- **TDesign**：官方 README 写「用 Design Token 扩展风格」，入口落在色彩指南。多技术栈宣称 API 对齐；token 是跨栈皮肤开关，不是 Ant 那套 Seed 算法。
- **Arco**：粒子变量 + Less `modifyVars`，或 [Design Lab](https://arco.design/themes)。主题页写明实质是 **CSS Custom properties，不兼容 IE**；要 IE 得用 postcss 消掉变量。默认蓝主题叫 ArcoBlue。
- **Semi**：介绍写「数千个」变量，分层到全局和组件。运行时明暗切换走 **CSS 变量**；不换运行时的量走 Sass。定制出口是 [DSM](https://semi.design/dsm)，可发 npm 主题包。Tokens 页：16 色相十阶；`AI general` 是 `linear-gradient()`，不能当 `background-color`。未支持全局行高、字距、媒体查询。默认英文字体 Inter **不打进包**。

### 暗色是四条实现，不是一个开关

Ant 设计页把暗色定义成「整套 UI 换成深色」，原则是舒适与信息层级不翻；色板仍是 12 套，靠透明度和生成工具出暗色阶。实现上改的是 `theme.darkAlgorithm`，不是手改每一个 Alias。

TDesign 有独立深色指南页，和 Ant 算法、Semi 的「任意主题自动带深色」不是同一句话。

Semi 介绍：任意主题自动支持深色，可运行时切，可**局部区域**开深色（SDK / 插件）；也能跟系统主题走。暗色依赖 CSS 变量，介绍写 IE11 及以下不行。

Arco 官方另有 [暗黑模式](https://arco.design/react/docs/dark)（仓库 README 列出）。主题页已声明 CSS 变量合同；不要把 README 兼容表的 Edge 16 理解成「暗色也能在 IE 跑」。

### 拒非授权译本

B2-ZH 只收这四家**官方中文站**。下列不进本页、不当来源：

- Material Design、Apple HIG、Fluent、Carbon 的民间中文译本、未授权手册、镜像站；
- 把 `antdv.com` / NG-ZORRO 写成 Ant 设计规范真身；
- 旧 Gitee / 第三方「antd 中文手册」若宿主不是 `ant.design`（或同文的 `ant-design.antgroup.com`）。

`ant-design.antgroup.com` 与 `ant.design` 同文双宿主。本页枢纽按 B2-ZH 用 `ant.design`。Element Plus、Naive UI、Vant 等未列入本批，另开账本。B3-Gov 的 GOV.UK / USWDS 是政务体系，不是本页。

## 必须保留的冲突

- **映射 ≠ 采用。** 本仓库没有因此改用 Ant / TDesign / Arco / Semi。本页不是已采用皮肤。
- **四家不是一套。** 价值观、色板套数、token 载体、官方框架表都不同。不要并成「中文 Ant」。
- **Arco ≠ Semi。** 同公司，两套语言、两套工具链（Design Lab vs DSM）。
- **Ant Vue 是社区，TDesign Vue 是官方。** 不要用「Vue 也能用」并成一条实现合同。
- **TDesign 稳定面不齐。** 桌面三栈与小程序、移动 Vue 为 LTS；移动 React / Flutter / Uniapp 为 Alpha。站点页脚 `undefined` 不覆盖 README。
- **Semi 无障碍两套口径。** 首页「所有组件」；介绍承认键盘与焦点未全覆盖，并指向 A11y Issue。符合性仍看 [[concepts/无障碍与包容设计]]。
- **Semi token 数量。** 介绍「数千」；营销壳「3000+」。本页不把营销数写成规范合同。
- **Token ≠ DTCG。** 四家各自的变量表不是 2025.10 CG 终稿的交换格式，见 [[concepts/视觉CSS与设计token]]。
- **Ant 4.x less ≠ 5/6 Token。** 现行主路径是 CSS-in-JS；`zeroRuntime` 才回到静态 CSS。
- **Arco 兼容表 vs 主题页。** README 仍列旧浏览器；主题页写 CSS 变量不支持 IE。暗色 / 主题以主题页为准。
- **拒非授权译本。** 与「中文资料更好读」不构成收进本页的理由。

## 例子

- 正例：改 Ant 主色只动 Seed `colorPrimary`，让算法出 Map / Alias；不要手写一整页 `#1890ff` 的组件覆盖当「官方主题」。
- 正例：TDesign 跨 Vue / React 对同一套设计指南，查的是 `tdesign.tencent.com` 与官方仓库，不是 Ant 社区 Vue。
- 正例：Semi 暗色用颜色 token，不用写死 hex；局部深色给 SDK 包一层，而不是给整页 `filter`。
- 正例：Arco 换品牌色走 Design Lab 或 `modifyVars` 的粒子变量（如 `arcoblue-6`）。
- 反例：把四家色板阶数（Ant 12、Arco 13、Semi 16）并成「都是十色」。
- 反例：把飞书主题、Byte Design、Ant Design Mobile 写成 B2-ZH 第五家。
- 反例：用民间 Material 中文手册给卡做「中文设计系统」。
- 反例：因本页出现 `antd` 就写进 recipe / 发卡依赖。

## 边界与易混概念

- 不包括：本仓库已采用哪套皮肤、卡 JSON/PNG、成品中后台。
- 不包括：CLREQ / 竖排 / 注音，见 [[concepts/CJK排印与竖排]]。
- 不包括：DTCG 交换格式、Style Dictionary 流水线。
- 不包括：无头库（Radix / Base UI / Zag）。这些体系带默认皮肤；无头不管外观，见 [[concepts/无头组件与根节点]]。
- 不包括：原子 CSS 引擎本身，见 [[concepts/Tailwind与原子CSS]]。
- 不包括：四家之外的续名单（Element Plus / Naive / Vant 等），见 [[queries/第四批蒸馏目标]] B4-ZH。
- 易混：设计系统 ≠ 组件库 npm 包 ≠ 设计价值观文案。没有 React 也能读规范；有包不等于采用了规范。
- 易混：官方实现 vs 社区实现。Ant 的 Vue 是社区；TDesign / Arco 的 Vue 是官方生态。
- 易混：Semi 首页营销「所有组件键盘与焦点」vs 介绍页「尚未在所有组件上完备」。符合性仍看 [[concepts/无障碍与包容设计]] 的 WCAG / APG，不看营销句。

## 映射到本仓库

映射，不是选型。

稳定卡和工坊今天的壳是宿主挂载、TH iframe、git-mount blob，见 [[concepts/酒馆宿主与iframe分层]]。四家若只当对照：Ant 的 ConfigProvider 必须和脚本所在 `window` 同一棵树，静态 Modal 还是另一棵；Semi / Arco / TDesign 的 CSS 变量跟的是**那份文档的根**，框内改不了宿主，宿主变量也进不了跨域框。Semi 介绍声称组件可在 Shadow DOM 工作，这仍是库合同，不是卡侧已经用 Semi。

[[concepts/前端设计库/README-前端设计库]] 的挑选器「加入候选」只写本机清单，不等于采用本页任何一家。嵌入宿主的卡 UI 仍优先 `data-*` / BEM，见 [[concepts/前端架构名词与取舍]]。色板与增量字体合同见 [[concepts/COLRv1与增量字体]]；静图格式见 [[concepts/媒体格式与编解码]]。

本页不写「已采用 Ant / TDesign / Arco / Semi」。
