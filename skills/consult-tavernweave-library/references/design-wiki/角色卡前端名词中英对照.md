# 角色卡前端名词中英对照

工作区口语 ↔ 代码标识。分三层：**酒馆宿主**（ST 自己的窗和 chrome）、**TH iframe**（能跑 JS 的框）、**卡协议**（`data-*` / 壳 / 工坊）。iframe 全表和净化钩子在 [[concepts/酒馆宿主与iframe分层]]；卡侧挂载点在 [[concepts/角色卡DOM与挂载点]]。

2026-08-13 起：星月 / 交错 / 怪谈是稳定发卡名词真源；末日 / 终末只当设计档名词。实现摘录保持原样，不把整文件搬进 Wiki。

## 宿主 chrome（ST 主文档）

这些在宿主页上，不在消息 iframe 里。私有 DOM，不是公开 API。

| 中文 | English / identifier | 含义 |
|---|---|---|
| 宿主页 | host document | SillyTavern 主页面 |
| 聊天列表 | `#chat` | 楼层容器 |
| 楼层块 | `.mes` | 一条消息 |
| 楼号 | `[mesid]` | ST 属性。`chats.js` 用 `.mes[mesid="${id}"]` |
| 最新楼 | `.last_mes` | 当前最后一条 |
| 正文槽 | `.mes_text` | 渲染管线终点；碎片 HTML 进这里 |
| 推理块 | `.mes_reasoning` | 与正文并列 |
| 主聊天壳 | `#sheld` | 宽度 `--sheldWidth`；移动端安全区 |
| 发送区 | `#form_sheld` / `#send_form` | 底部输入 chrome |
| 输入框 | `#send_textarea` | 选项桥 / 小手机填这里 |
| 发送钮 | `#send_but` | 宿主发送链 |
| 魔棒菜单 | `#extensionsMenu` / `.extensionsMenu` | 控制中心入口 |
| 顶栏 | `#top-settings` / `#navbar` / `#sheld_header` | 抽屉要避开 |
| 滑动页 | swipe | 同一楼的备选生成 |
| 快速回复 | QR, Quick Replies | 宿主条；别在 iframe 里重定义 `triggerSlash` |
| Custom CSS | 用户主题 CSS | 写宿主；引用消息 class 要带 `custom-` |
| movingUI | 可拖面板 | ST 内部；不当卡公开 API |
| toastr | 浮动通知 | 显示在宿主 |

## iframe 与窗

完整分层、创建者、全局表见 [[concepts/酒馆宿主与iframe分层]]。这里只留最常喊错的。

| 中文 | English / identifier | 含义 |
|---|---|---|
| 脚本框 | `TH-script--{name}--{id}` | TH 跑卡内脚本 |
| 消息框 / 前端界面 | `TH-message--{楼号}--{序号}` | TH 把 ` ```html ` + `<html>` 渲成 iframe |
| TH Blob 渲染 | 扩展设置 | TH 自己的 blob src，方便看日志 |
| 卡内真身框 | `blob:` / `#xy-sb-inner` | 卡自己造的；默认没有 TH 全局 |
| 双窗口穿透 | `hostWindow()` / `hostDocument()` | 从框里摸宿主 |
| 变量桥 | `injectBridge` | 只给没有 TH 的真身框补 `$` / `Mvu` |
| 认窗 | `getIframeName()` | 官方工具函数 |
| 重载框 | `reloadIframe()` | 等于 `location.reload()`，共享接口会丢 |
| 代码块前端 | ` ```html ` 渲染器 | 灵感来自阡濯 html 代码注入器；要有 `<html></html>` |

**不是 iframe：** OMNI、气泡、行动选项。它们是 `.mes_text` 里的净化 HTML。

## 净化与样式作用域

| 中文 | English / identifier | 含义 |
|---|---|---|
| 消息净化 | `MESSAGE_SANITIZE` / DOMPurify | ST 渲染最后关 |
| class 前缀 | `custom-` | 每个 class token 加前缀；豁免 `fa-*` / `note-*` / `monospace` |
| 样式标签替身 | `<custom-style>` | `<style>` 进净化前的编码标签，**不是** `style=""` 改名 |
| 楼内 CSS 作用域 | `.mes_text ` 前缀 | decode 时给选择器加前缀 |
| 协议属性 | `data-*` | 净化放行；消息楼 JS/CSS 挂钩 |
| 宿主主题变量 | `--sheldWidth` `--SmartThemeBodyColor` `--fontScale` | 在宿主根节点；iframe 不继承 |

## 壳与运行时

| 中文 | English / identifier | 实现要点 |
|---|---|---|
| 控制中心 | Control Center, `control_center.js` | 卡内功能容器；TH 脚本按钮入口 |
| 状态栏 / HUD | Status Bar, HUD, `status_bar_regex.html` | 前台展示与重交互 tab |
| 开局页 | Opening page, `first_message_opening.html` | 封面启动；first_mes 不塞大 HTML |
| 远程挂载壳 | git-mount loader / shell | 卡内薄壳 fetch runtime 真身 |
| 真身 | payload, `status-bar.html` | 真正的 HUD HTML |
| 运行时 | runtime | `runtime/xingyue/<ver>/` 一类路径 |
| 运行时基址 | `XY_RT_BASE`, `BASE`, `BASE_CF` | 壳用来拼 CDN/git 地址 |
| 变量桥 | `injectBridge` | blob iframe 补 `$` / `Mvu` / `getVariables` |
| 失败即关 | fail closed | 契约无效则停用，不绕过 |
| 控制壳 | `control-shell.js` | 末日之后：桌面入口 + 移动抽屉 + 宿主单例 |
| 手机桥 | `phone-bridge.js` / `kdn_bridge.js` | 白名单通信；怪谈笔记规则三写，末日之后 11 根只读 |
| 小手机真身 | `phone-hud.html` / `kdn_phone.js` | 笔记 App 或 OS 式终端 |
| 纯卡内 | card-local only | 末日之后：无工坊、无开局页、无远程 loader |
| 最新楼只读 | `Mvu.getMvuData({ type: 'message', message_id: 'latest' })` | 末日之后 P3；禁止 `replaceMvuData` |

```javascript
// 状态栏壳读基址：优先控制中心注入，否则内联
const base = window.XY_RT_BASE || BASE;
```

```javascript
// 末日之后 P3：只读当前最新楼 11 根，不写回
const data = Mvu.getMvuData({ type: "message", message_id: "latest" })
  || getVariables({ type: "message", message_id: "latest" });
```

隔离事实：控制中心脚本框与状态栏消息框不是同一 `window`，`XY_RT_BASE` 经常到不了壳，出卡必须改内联版本段。星月这条路与末日之后的纯卡内壳是两条产品线，不要混装远程 loader。

```javascript
// media_library.js 概念：扫挂载点再拉 runtime 模板
document.querySelectorAll("[data-xy-omni]").forEach((el) => {
  const type = el.getAttribute("data-xy-omni"); // analysis | done | progress
  // fetch(`${XY_RT_BASE}/omni-${type}.html`) → {{CONTENT}} → wireOmniButtons

```

```javascript
// 不跨同名标签（analysis_omni）
const findRegex = /<analysis>\s*((?:(?!<\/?analysis>)[\s\S])*?)\s*<\/analysis>/gi;
```

SillyTavern 会给消息 class 加 `custom-` 前缀，所以：

```css
/* 会失配 */
.omni-analysis summary::marker { display: none; }
/* 要用 */
[data-xy-omni="analysis"] summary::-webkit-details-marker { display: none; }
```

## 边界

- 宿主选择器（`#send_textarea`、`#extensionsMenu`）是 ST 私有 DOM，不是稳定公开 API；新代码优先 TH 命令。官方 iframe 名以酒馆助手文档为准，见 [[concepts/酒馆宿主与iframe分层]]。
- 未把 Zod 里的私密身体字段展开进本页；那是变量 schema，不是前端壳名词。
- 终末浮城多数前端仍是沙盘，标识符以设计稿与星月/怪谈笔记已有实现为准。
