# 开局页路径

自定义开局是**一次性初始化器**：玩家填完，发出一条真实玩家开局消息，然后回到正常多楼层。若首楼此后还代理每一轮输入和生成，那就滑进 C5 同层前端。三张稳定卡都不走 C5。指南：`C10_开局页与自定义开局.md`。

## 三类开局

| 类型 | 生命周期 | 稳定卡 |
|---|---|---|
| 普通 `first_mes` | 展示一条首消息 | 星月 4.0.0 的 `first_message_opening.html` 只留标记行 |
| `alternate_greetings` | 首消息候选 | 可用，但不是星月主向导 |
| 自定义开局页 | 向导 → 提交真实玩家消息 → 退出 | 星月远程开局；怪谈楼内授予者表 |

## 星月 4.0.0

```text
first_mes 标记
  → 正则 opening_expand 在楼里放 data-xy-opening-remote
  → 控制中心按 phase/remote-state 拉 runtime 开局真身
  → 草稿 OpeningDraftV2（按聊天 metadata UUID 分区）
  → 预览 / 校验
  → 提交：世界书管理器写身份，再发真实玩家开局发言
  → 开局页卸掉，后面是普通楼
```

`data-xy-remote-state`：`idle` / `loading` / `loaded` / `error`。失败可 `data-xy-opening-retry`。契约未就绪则 fail closed，见 4.0.0 工坊竞态修复。

死守：`first_mes` 不塞大 HTML，否则上下文爆炸（C2 避坑 7.5）。剥离用 `opening_prompt_strip_regex.html`。

开局向导可以复用控制中心的世界书/媒体能力，但不能让控制中心变成第二套提交真值。C10：一个草稿模型，一个提交事务。

## 怪谈 1.0.9

没有星月那套远程开局页。楼内 `data-kdnopen-root` 表单，`data-kdnopen="字段名"` 收集授予者态度等，`data-kdnopen-go` / `-skip` 写入输入框后由玩家发送。地理进 `环境`。桥在 `kdn_bridge.js`。

## 交错 v2.6.2

同族控制中心入口。不把星月远程开局当本卡必装件。`first_mes` 是玩家手册；起源十选一写在**一条** `alternate_greetings` 里（不是十条问候）。标题见创意库世界观页。C.Z.03 / C.Z.20 纪年冲突未裁。

## 边界

- 开局页 script 在消息楼里不一定执行（C2 7.8）。星月把逻辑放控制中心 / runtime，不靠楼内裸 `<script>`。
- 末日之后设计档去掉开局页，不在本路径。
