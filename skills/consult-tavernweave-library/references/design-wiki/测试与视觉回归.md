# 测试与视觉回归

本页不是已采用测试栈，也不是工坊 CI 配方。检索时间：2026-08-15（入口直读日 2026-08-14）。账本枢纽是 [[queries/第二批蒸馏目标]] **B2-Test**；12 条入口、旧文档 404 与三条合同见 [[10-收件箱/写回候选/第四批-B4-VRT]]。只谈公开文档，不写攻击、凭证或 Percy 教程。

## 一句话定义

测试与视觉回归不是一种工具。Playwright 是跑用例的 **runner**；像素对照、ARIA 树快照、axe 扫描、Testing Library 查询、MSW 网络桩、Chromatic 云回归是**不同合同**。听到「做了 VRT」先问：比的是像素、无障碍树，还是云端档案。

## 为什么重要

HUD、文档站、动效和 iframe 都会让「看起来没坏」说谎。像素金图会因操作系统、浏览器版本、电源和动画抖动；ARIA 快照抓不到色偏；axe 过了仍可能不符合 WCAG。混用旧 URL 或把 Chromatic 写成 MIT，会装错包、链到 404。本页只分层，不选栈。前端取舍见 [[concepts/前端架构名词与取舍]]，不在这里重开架构页。

## 如何运作

七层不要并成「一种测试」。

### Playwright runner

[Intro](https://playwright.dev/docs/intro) 管安装、项目脚手架和用例怎么跑。截图断言**只**在 Playwright test runner 里工作。它提供 `getByRole` 等定位器，但 **Playwright 不是 Testing Library**，也不是组件测试库。本页不写本仓库 CI 配方。

### 像素对照：`toHaveScreenshot`

[Visual comparisons](https://playwright.dev/docs/test-snapshots) 写明：`expect(page).toHaveScreenshot()` 会等到**连续两张**截图一致，再跟金图比。比较库是 pixelmatch。可调 `maxDiffPixels` / `stylePath`（用 CSS 藏动态块）。默认 PNG；文件名用 `.webp` 则存无损 WebP。金图目录是 `*.spec.ts-snapshots`，文件名带浏览器与平台（如 `chromium-darwin`）。官方警告：渲染随 OS、版本、硬件、电源、headless 变；基线必须在**同一环境**生成。首次跑会写金图；更新：`npx playwright test --update-snapshots`。

`toMatchSnapshot()` 仍在，但现行视觉页把它留给文本/二进制，不是像素主路径。旧文/博客常见 `expect(screenshot).toMatchSnapshot('x.png')`——那是另一条合同。

动效会抖基线。大位移、循环动画、未冻结的时间轴会让连续两帧对不齐，或让金图在 CI 里闪红。映射 [[concepts/动画库与动效管线]] 的 `prefers-reduced-motion` 与可关动效，不是新发现，也不在本页重写缓动。

### ARIA 快照

[Aria snapshots](https://playwright.dev/docs/aria-snapshots) 比的是 YAML 角色树（role / name / 状态），不是像素。默认跨浏览器只存一份 `.aria.yml`。这能抓住「按钮没了 / 标题级错了」，抓不住「差 2px / 色偏」。不要和上一节并成「一种 snapshot」。

### axe-core

Playwright 无障碍页官方接 `@axe-core/playwright` 的 `AxeBuilder`。[axe API](https://www.deque.com/axe/core-documentation/api-documentation/)：本地跑、不连第三方服务器；能进嵌套 iframe；**隐藏区不测**。`AxeBuilder.analyze()` 只看调用瞬间的已渲染树；隐藏菜单/模态要先打开再扫。`exclude()` 会排除子孙且关掉该节点上**全部**规则。`setLegacyMode()` 官方标最后手段，会关掉跨源 frame 测试。

官方示例 `withTags(['wcag2a','wcag2aa','wcag21a','wcag21aa'])`，**没有** `wcag22*`。axe 标签表有 `wcag22aa`，**没有** `wcag22a`。`best-practice` 与 `experimental` 不是符合性标签。

Playwright 无障碍页自己写：自动扫描只能抓一部分；许多问题只能手测。它推荐 [Accessibility Insights for Web](https://accessibilityinsights.io/docs/web/getstarted/fastpass/?referrer=playwright-accessibility-testing-js) 做 **WCAG 2.1 AA** 人工走查——注意是 2.1，不是本库已蒸的 WCAG 2.2 Rec。

**axe 过 ≠ WCAG 符合**；跟 APG ≠ Rec。规范分层见 [[concepts/无障碍与包容设计]]，本页不重抄那一页。

### Testing Library 查询优先级

[About Queries](https://testing-library.com/docs/queries/about/) 不是 runner。官方优先序：`getByRole` → label → placeholder → text → displayValue → alt → title → `getByTestId`（最不优先）。账本 B4-VRT-06 收成主链 `getByRole` → label → placeholder → text → testid。

Testing Library 的 `getByRole` 与 Playwright 的 `getByRole` 同族优先级，但 TL 不是 E2E runner，PW 不是组件库。不要把一份查询示例改两个库名交差。

### MSW v2

[Quick start](https://mswjs.io/docs/quick-start) 现行是 `http` + `HttpResponse`。Node 用 `setupServer`，浏览器用 `setupWorker`。MSW v1 的 `rest` / `graphql` 命名已不是 quick start。本页只记桩合同，不写拦截绕过或凭证。

### Chromatic 云回归

Chromatic 是**商业云工具链，不是 MIT 库**。枢纽：[docs](https://www.chromatic.com/docs/)（`docs.chromatic.com` 同壳）。

Playwright 线：把 `@playwright/test` 换成 `@chromatic-com/playwright` 的 `test` / `expect`，再 `npx chromatic --playwright`。Storybook 线：现包 `@chromatic-com/storybook`；旧 `@chromaui/addon-visual-tests` **已弃**，旧 npm 页仍在，不当新装入口。`chromatic.viewports` 目录标 **legacy**，改走 Modes。

营销页写它存 DOM + 样式 + 资源档案，不只一张 PNG。Flake filter / 暂停动画是云侧稳定手段，对不上 Playwright 本机 `stylePath`。Playwright 视觉页要「同一环境」；Chromatic 卖点是云端统一浏览器。不要写成同一条 VRT。

Storybook 官方视觉测页把跨浏览器视觉测指到 Chromatic。文档站怎么生成见 [[concepts/文档站生成器]]，本页不重开生成器。

## 必须保留的冲突

- 旧文用 `expect(screenshot).toMatchSnapshot('x.png')`；现行视觉页主推 `toHaveScreenshot()`。两条都还在，合同不同。
- Playwright 视觉页要「同一环境」；Chromatic 卖点是云端统一浏览器。不要写成同一条 VRT。
- `toHaveScreenshot` 是像素；`toMatchAriaSnapshot` 是 YAML 树。不是一种 snapshot。
- Playwright 无障碍示例钉 WCAG 2.0/2.1 标签；本库无障碍页钉 2.2 Rec。两边都留。
- Testing Library `getByRole` 与 Playwright `getByRole` 同族，但 TL ≠ E2E runner，PW ≠ 组件库。
- MSW v1 的 `rest` / `graphql` 已不是 quick start；现网是 `http` / `HttpResponse`。
- `@chromaui/addon-visual-tests` 已改名 `@chromatic-com/storybook`。旧包不当新装入口。
- Chromatic `/docs/visual-testing` 与 `/docs/visual-tests` **硬 404**；不要从旧教程抄这两条。
- Chromatic **不是 MIT**。
- iframe / Shadow DOM：axe 测嵌套 iframe，跨源要看 legacy；Chromatic 另有 Shadow DOM 交互测。映射 [[concepts/酒馆宿主与iframe分层]]，不是已采用。
- 本页映射行业测试分层；**不是**「本仓库已采用 Playwright / axe / Chromatic」。

## 例子

- 正例：像素回归走 `/docs/test-snapshots` 的 `toHaveScreenshot()`；金图在同一 CI 镜像里生成。
- 正例：要锁「这个按钮还在、名字没丢」用 ARIA 快照，不拿它当色偏检测。
- 正例：axe 只当自动扫描层；符合性仍手测，并回到 [[concepts/无障碍与包容设计]] 的 WCAG 2.2 Rec。
- 正例：组件查询按 Testing Library 优先序；网络桩用 MSW v2 的 `http` / `HttpResponse`。
- 反例：把 `toMatchAriaSnapshot` 写成像素 VRT，或把 Chromatic 写成 MIT。
- 反例：从旧教程抄 `/docs/visual-testing`、`/docs/test-screenshots`，或新装 `@chromaui/addon-visual-tests`。
- 反例：axe 绿了就写「已符合 WCAG」；或示例只开 `wcag21aa` 却声称覆盖 2.2。
- 反例：未冻结动画就锁像素金图，再把闪红当成「CI 坏了」。

## 边界与易混概念

- 不包括：本仓库 CI yaml、卡 JSON/PNG、成品皮肤、凭证、攻击或绕过、Percy / Lost Pixel / 付费课。
- 不包括：k6 / Pact（B3-Load）、Storybook 生成器全文（B3-SB；本页只收 Chromatic 合同）。
- runner ≠ 像素断言 ≠ ARIA 快照 ≠ axe 扫描 ≠ 查询库 ≠ 网络桩 ≠ 云回归。
- `page.screenshot()` ≠ `toHaveScreenshot()`。前者取像素，后者是 runner 内的金图断言。
- axe 过 ≠ WCAG 符合；APG ≠ Rec。不在本页重写规范层。
- Chromatic 云档案 ≠ Playwright 本机 PNG 金图。
- 易混：听到「snapshot」就以为一定是像素。先问文件是 `.png` / `.webp` 还是 `.aria.yml`。

## 映射到本仓库

当前工坊没有已采用的 Playwright / axe / MSW / Chromatic 栈。本页只问：若要测，先分清比的是哪一层，不要把七种合同写成一种「上了测试」。

对齐方式是**按层选合同**：本地像素走 `toHaveScreenshot`；锁语义走 ARIA 快照；自动扫描走 axe 并承认缺口；组件查询走 Testing Library 优先序；网络桩走 MSW v2；跨浏览器云回归若选 Chromatic，按现行包名与 `/docs/`，不要抄 404 旧径。这是「测试分层要稳定」，不是「工坊必须上 Chromatic」。

角色卡只在这里点名、不当过滤器：HUD / 悬浮层动效会抖像素基线，先看 [[concepts/动画库与动效管线]]；跨文档 iframe 与 Shadow 的扫描范围见 [[concepts/酒馆宿主与iframe分层]]；文档站若做视觉测，生成器归 [[concepts/文档站生成器]]，本页只标 Storybook 官方把跨浏览器视觉测指到 Chromatic。前端怎么切页面见 [[concepts/前端架构名词与取舍]]。本 Vault 不收测试账号或云服务令牌。
