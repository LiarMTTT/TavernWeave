# 斜杠命令与宿主发送链

稳定卡从 iframe / 小手机把字送到酒馆，不靠直接改输入框再点发送。走酒馆助手 `triggerSlash`。指南 B2 是 STScript 总册；本页只记三张稳定卡实际用的几条。B2 全套命令**未走**。

## 稳定卡用到的

| 命令 | 谁调 | 干什么 |
|---|---|---|
| `/setinput <文本>` | `options_bridge.js`、`kdn_bridge.js` | 把选项或开局设定填进 `#send_textarea`。换行写成 `{{newline}}` |
| `/send <文本>` | 同上，直发模式 | 追加一条玩家消息 |
| `/trigger` | 跟在 `/send` 后面用管道 | 触发生成。`/send` 单独**不会**开生成 |

直发实现（星月 4.0.0 / 怪谈同构）：

```text
/send <选项> | /trigger
```

管道里的 `|` 若出现在用户文本里要先转义。

找命令接口：`TavernHelper.triggerSlash`，或注入的自由函数 `triggerSlash`。没有就 fail，不要退化成 `input.value = …; send_but.click()` 当正式路径。

读当前输入仍可 `hostDocument.querySelector('#send_textarea')`，那是私有 DOM，只用来拼接「已有草稿 + 新选项」。

## 和 QR 的坑

TH 文档：不要在前端代码里自己定义 `triggerSlash`，会盖掉扩展的函数，QR 失效。卡侧桥只调用，不声明同名函数。

## 事件：什么时候重扫楼

| 事件 | 谁听 | 干什么 |
|---|---|---|
| `tavern_events.CHAT_CHANGED` | 选项桥、媒体库、控制中心 | 切聊天后重扫 / 延时重挂魔棒 |
| `MESSAGE_UPDATED` / `GENERATION_ENDED` | 选项桥 | 新楼选项出现后渲染 |
| `USER_MESSAGE_RENDERED` / `CHARACTER_MESSAGE_RENDERED` / `MESSAGE_SWIPED` | 媒体库 | 气泡、OMNI 挂载 |

控制中心生产模式：`CHAT_CHANGED` 后 **250ms** 再 `ensureWandEntry()`，等 ST 重建顶栏。不要假定按钮还在。

## 边界

- 本页不是 B2 命令大全。`/gen` `/inject` `/let` 等稳定卡主路径不用。
- 开局提交：怪谈用 `/setinput` 填「【开局设定】…」让玩家自己发；星月远程开局另有世界书事务 + 真实玩家消息，见 [[concepts/开局页路径]]。
