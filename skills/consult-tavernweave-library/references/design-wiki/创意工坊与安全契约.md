# 创意工坊与安全契约

工坊是星月（以及计划中的终末）的内容管线，不是 HUD。指南：`E5_创意工坊与扩展生态.md`。怪谈、末日之后设计档**不装**工坊。

## 四层不要叫成「插件」

| 层 | 载体 | 本卡怎么用 |
|---|---|---|
| ST UI Extension | 宿主扩展 | 不管 |
| ST Server Plugin | Node | 不管 |
| TH 卡内脚本 | ScriptTree / srcdoc | 控制中心、Zod、媒体库 |
| 创意工坊 | 卡内客户端 + Gateway + 存储 | 只写受控世界书条目 |

工坊包**不是**任意脚本、prompt patch 或 MVU patch。导入只碰聊天世界书，例如 `[世界因子]当前设定`、`[创意工坊][类型]标题`。

## ScriptTree 与魔棒

当前 TH 用 `ScriptTree[]`（或卡内 `tavern_helper.scripts` 树），不是旧 `scripts` 对象。

`getButtonEvent(buttonName)` 匹配 **`button.buttons[].name`**，不是脚本 `name`。交错控制中心按钮名是 `交错宙域控制中心`。星月控制中心 ScriptTree 上没有按钮，入口另挂 `#extensionsMenu`（私有 DOM，`CHAT_CHANGED` 后要重挂）。

## 星月 4.0.0 契约时序

云酒馆曾出现：控制中心已启动，安全契约 `1.1.0` 未就绪，工坊 runtime 抢跑。4.0.0 把契约内嵌进控制中心：

```text
启动 CC
  → 校验内嵌契约 1.1.0（远程仍首选）
  → 双失败 → fail closed，不加载工坊 runtime
  → 成功 → 再开工坊 iframe
```

Bridge 只暴露有限 action（handshake / getEntries / upsertWorkshopEntries …），要 origin allowlist，禁止 `postMessage('*')`。

## 边界

- 终末浮城长期内容管线在设计档里，没有稳定发卡工坊。
- Gateway token、OAuth、Cloudreve 不进本 Vault。
- 详细 schema 以工作区 `rolecard-diy-workshop/schemas/` 为准，本页不复制。
