# 概念分级

本库的概念页按**职责分层**，不按「能不能用在角色卡上」删名词。行业正文仍在根目录 `concepts/*.md`；挑选用的目录和 HTML 另放，避免搬页断链。

## 五级

| 级 | 名字 | 放什么 | 不当成什么 |
|---|---|---|---|
| L0 | 规范 | W3C / MDN / RFC 合同 | 本仓库皮肤 |
| L1 | 概念 | 已蒸正式页：定义、冲突、映射 | 成品实现 |
| L2 | 库 | 可打开源码或文档的实现 | 已采用栈 |
| L3 | 生成器 | 滑块、配方、Demo | 设计系统 |
| L4 | 灵感 | 画廊、市场、截图站 | 许可已核 / 可商用 |

L0–L1 先认合同。L2–L4 用来挑手感和入口，挑中的项要再核许可与兼容，不能从挑选器直接升格成「本仓库已采用」。

设计 / 动效侧栏：点一条就出沙盘；没有沙盘、能嵌的出源站。不要默认要点片。账本能实装的分路挂沙盘；Kafka / Helm / 规范长文等仍只出要点。规范、HIG、GitHub、价目、长文、基建合同仍不嵌，也不造假沙盘。

243 路分路已标主题并挂最近的正式概念页（没有专页的不硬造）。设计 / 动效仍只收能当样本的条，不是把八批入口全搬进侧栏。

账本行仍以 [[queries/前端视觉与灵感站点蒸馏目标]] 至 [[queries/第八批蒸馏目标]] 和收件箱分路原稿为真源。挑选页只做筛选面，不替代查询页，也不把账本升成已采用。
