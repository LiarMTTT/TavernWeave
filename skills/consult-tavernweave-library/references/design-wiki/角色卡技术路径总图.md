# 角色卡技术路径总图

三张已验证稳定卡共用一条主链。指南库按主题分册（A/B/C/D/E），本页按**运行时先后**把它们串起来，并指到 Vault 里对应的实现页。指南原文仍在 `角色卡工作区/ST开发指南DB/`，不搬进本 Vault。

指南库置信度是 medium-high，手册里的悬案仍以手册为准。本页只记三张稳定卡实际走了哪条路。

## 主链（生成一轮）

```text
世界书扫描注入 prompt          ← A3 / [[concepts/世界书注入路径]]
        ↓
模型输出正文 + <UpdateVariable>  ← B1 / [[concepts/MVU变量闭环]]
        ↓
MVU bundle 打 JSONPatch
        ↓
消息渲染：宏 → 正则 → Markdown → .mes_text
        ↓                          ← A5 A6 / [[concepts/消息渲染与正则管线]]
显示层挂载：OMNI / 气泡 / 选项 / 开局壳
        ↓                          ← [[concepts/角色卡DOM与挂载点]]
HUD 读 stat_data 刷新
        ↓                          ← C2 / [[concepts/控制中心与状态栏]]
入口打开：魔棒 / 悬浮球 / 抽屉 / 浮窗
                                   ← C11 C12 C13 / [[concepts/入口外壳与HUD宿主]]
```

旁路（不挡主链，但稳定卡都有）：

- 开局一次性向导 → [[concepts/开局页路径]]（C10）
- 星月 git-mount 真身 → [[concepts/git挂载与远程真身]]（D1）
- 怪谈/星月小手机挂宿主 body → [[concepts/小手机与宿主桥]]
- 行动选项填输入框或直发 → [[concepts/行动选项桥]]
- 头像立绘四源 → [[concepts/媒体库路径]]
- 组件回落与回封 → [[concepts/组件库registry与recipe]]、[[concepts/打包回封路径]]

## 三张稳定卡走法差在哪

| 路径 | 星月 4.0.0 | 交错 v2.6.2 | 怪谈 1.0.9 |
|---|---|---|---|
| 变量 | MVU + 双 Zod + 13 根级回落史 | 同族 MVU，宙域/机体根 | MVU + 双 Zod，15 根回落史 |
| HUD | git-mount 真身 + 抽屉/浮窗/小手机 | 卡内 `status_bar_regex.html` | 小手机挂宿主 body |
| 开局 | 远程开局页，first_mes 不塞大 HTML | 控制中心，无星月那套远程开局 | 楼内 `data-kdnopen` 表 |
| 远程 loader | 要 | 控制中心本地为主 | 卡内脚本，HUD 内嵌 |
| 工坊 | 要，4.0.0 契约内嵌 | 要控制中心 | 无星月工坊 |

终末浮城、末日之后是未出生设计档，不进本表。
