# E06：原生、模板与控制器的共同输出预算

[静态体积指标](static-budget-contract.md)已有打包层预算；本节检查各入口合并到一次实际模型请求中的输出。原生、条目内条件、显式读取和多个控制器可以同时产生候选。一个控制器自己的 Set 去重，不等于最终提示已去重。

## 一份身份与一次仲裁

1. 从 [E05 目标映射](../../sillytavern-database-rolecards/references/worldbook-target-state-contract.md)取得稳定内容身份；同义别名归同一实体，同一实体的不同资料仍有不同内容身份。书身份与 UID 保留，不重新编号。
2. 每个候选保留内容身份、权威来源/修订、入口、接收模型、必要性、依赖组与项目选定优先级。正文相同可提示重复，不能仅按文本哈希合并语义不同的条目；正文不同却声称同一权威版本应报冲突。
3. 在确能看见全部候选的阶段，统一处理原生入口和全部模板/控制器的候选，按声明的权威来源保留一份；候选未知或权威来源冲突时，不能静默任选。优先级是该项目的工程决定，不是固定 `order` 数字或模型品牌配方。
4. 若环境没有可核验的统一拦截点，先在设计上令两条路径互斥、由一个明确所有者输出，或捕获最终请求后检测并修复。不要假定模板里的局部集合能删除已经进入宿主的原生片段，也不要称检测器已阻止重复。
5. 对每个实际接收模型分别检查最终请求；额外更新模型并不自动需要所有正文。相同资料按设计发送给不同消费者，与同一请求重复是不同问题。

## 预算规格与失败路径

继续只维护项目已有的预算记录。声明总上下文及保留给系统/卡/历史/用户输入/回复的空间，再确定世界书输出能使用的份额。条数与字符数是可提前检查的工程护栏，**不是关键词数量配额**；具体上限按任务约定，不能把夹具数值当作通用上限。

- 先确保必要正文与其依赖组可整体保留，再依优先级加入可选资料。相同优先级的处理应稳定且可解释，不暗借 UID 重排内容。
- 超额时采用已选策略：略去低优先级可选项、替换为作者批准的摘要，或停止依赖材料不足的生成。保留被省略内容身份及原因；不能截半条规则、删掉否定/条件，或自动把摘要写回存档。
- 必需内容自身放不下时报告预算不足，不能悄悄舍弃它后宣布通过。内容缺失与预算舍弃是不同诊断。
- 记录处理前后候选数、唯一内容数、输出字符数和最终 token 数。字符计数需说明单位；随包示意用 Unicode 码点而非 JavaScript UTF-16 长度。
- 必须使用目标模型对应的分词器测量实际最终请求的 token 数，记录模型/分词器身份、聊天包装及计量范围；字符数、文件字节数或粗估比例不能冒充实测 token。只测世界书片段也不能证明总请求未超限。
- `ignore_budget=false` 仅描述一个配置值，不证明显式读取已经计入宿主预算或按理想粒度裁剪。具体计数阶段按 [E03](../../sillytavern-api-reference/references/worldbook-version-verification.md)核验。

## 投影只改变本轮视图

完整状态由原所有者持久保存；输出层只读所需字段，构造副本/明确的只读视图。将持久状态、生成投影、UI呈现分开，不为了少占上下文修改存档。

0、false、缺失、null、空字符串按字段语义分别处理。折叠一个离场模块时，如果其中仍有有意义的值，保留项目要求的折叠标记或概要；不能把 0/false 都判空，导致有意义的模块被隐藏却没有提示。投影前后比对完整存储，不只看显示值。

自写隔离例让 `archivedModule` 含 `count=0`、`completed=false`：投影可只保留折叠标记，完整状态仍保留这两个有效值。另让原生入口和两个模板选择器同时提出桥梁规则，检查同一请求的去重；单个选择器自己的别名集合不能证明跨入口预算。

## 最小验收

复用 [E07 隔离夹具与观察](../../sillytavern-runtime-debug/references/worldbook-isolated-runtime-checks.md)：同义别名、两个控制器、原生+模板分别命中同一内容；再放入超额可选项和放不下的必要项。检查仲裁与降级原因、最终请求是否只留应有的一份、状态是否保持。静态示意通过只能证明示意规则一致，最终提示、实际分词和真实宿主执行仍单独验收。

字段、导出和 ID 保护仍由原负责技能处理。不接受固定位置万能论、品牌深度、固定顺序或关键词配额。
