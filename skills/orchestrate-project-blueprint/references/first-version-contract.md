# 第一版合同

## Core Spine

项目没有它就不成立的权威源、核心对象、主循环、关键状态与最低宿主能力。每项必须能指向实现责任和验证证据。

## First Playable / First Usable

第一版必须形成完整闭环：用户从明确入口进入，完成一次核心动作，看见真实状态变化，能处理至少一个失败路径，并得到可重复验证的结果。

必须写：

- 入口与目标用户；
- 主路径和最小数据/状态源；
- 必交付文件或界面；
- 明确不做的内容；
- 自动化、静态、真实宿主和驾驶员验收各自负责什么；
- 完成后停在哪里。

## Growth Tracks

首版验证后才进入的长期方向。每项写触发条件，不默认排进当前蓝图。

## Parking Lot

有价值但本轮不解决的想法、争议、外部依赖与高风险实验。Parking Lot 不是暗中承诺。
