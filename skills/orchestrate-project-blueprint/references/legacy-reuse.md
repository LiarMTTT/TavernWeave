# 稳定作品复用协议

脑暴早期明确问：是否有用户认可、已稳定运行或已完成验收的旧作品、组件、交互、设计案可以参考？若有，要求提供真实路径、仓库、版本或运行证据。

逐项记录：

| 决策 | 含义 |
|---|---|
| 复用 | 契约与宿主仍兼容，可直接承担新项目责任 |
| 改造 | 核心价值可保留，但接口、状态或视觉需要迁移 |
| 仅参考 | 只借鉴结构/审美/经验，不复制实现 |
| 拒绝 | 已知不稳定、过时、无授权或与新目标冲突 |

每项写来源、版本、稳定证据、新责任、迁移风险和需重验的门。不要因文件存在、年代久、用户喜欢或曾发布过就判定“稳定”。第三方资产仍按原授权执行。
