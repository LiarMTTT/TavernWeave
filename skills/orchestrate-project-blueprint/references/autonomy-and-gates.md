# 自治边界与证据门

`按蓝图开跑第一版` 只授权：在当前项目工作区内，按已确认 First Playable 修改源码/文档，运行安全的本地静态检查与自动化测试，并更新权威链。

它不授权：

- 修改用户级或系统级 `AGENTS.md` / `CLAUDE.md`；
- 安装、卸载、重装或改全局环境；
- 读取/写入密钥、付费 API、真实外部 POST；
- Git 提交、推送、合并、打标签、Release；
- 部署、发布、向第三方发消息；
- 删除或覆盖历史资料；
- 把自动化结果标成驾驶员/真机验收。

## 证据账本

四类证据分别报告：

1. automated：测试、验证器、构建器；
2. static-preview：文件、渲染、离线预览；
3. real-host：真实客户端、设备、运行时；
4. driver：用户明确验收。

一个门通过不能替代另一门。脚本以 `--automation` 验证权威时，禁止把状态写成 `driver-accepted`。
