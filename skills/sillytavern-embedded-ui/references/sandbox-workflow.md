# 按作品搭建前端沙盒：工作流程

TW 提供搭建规范，由 Agent 根据用户作品的真实源码，在项目约定的测试目录里实现沙盒。沿用作品的技术栈、预览服务与视觉风格，直接呈现要调试的前端，按需要添加调试控件。无需另做 TW 门户、欢迎页或通用演示应用。

沙盒是封装前的可选打磨。复用用户已有的采用／跳过决定；用户已经要求搭建时直接推进。明确跳过时不创建沙盒，也不阻塞制作、构建与真实酒馆检查。是否省时、能发现多少问题取决于项目和用法。

## 先确定要看的范围

1. 读取项目续接、版本、维护源码、构建入口、前端模块、宿主依赖和数据所有权。区分维护源、构建产物和测试副本，列明本次实际执行哪份文件。缺源码时如实说明，不从截图重画一个替身冒充原前端。
2. 列出本次范围内全部模块、子界面、入口、关键操作、依赖和事件。选单模块聚焦一处交互，或联合加载相关模块检查共享状态与相互影响；允许在测试中切换范围并更新记录。
3. 在项目测试目录搭建最小宿主适配层：它负责真实源码装载、隔离的状态读写、事件转发和 UI 参数。先核对项目现有启动方式，不编造统一命令或固定端口。只服务本次预览所需文件，保持私有材料在用户工作区。

接入要求见[项目适配合同](adapter-contract.md)，场景选择见[单模块与联合模拟参考](sandbox-recipes.md)。函数名和页面布局按项目决定。

## 一轮打磨

1. **对准源码。** 记录实际执行的入口、版本和文件 SHA-256；若是测试副本，同时记录维护源及差异。依赖文件也进入来源清单。未核对的散列记为 `unverified`，不能凭适配层的自报值宣称校验通过。
2. **还原运行关系。** 保留模块依赖的顶层窗口、消息 iframe、blob／srcdoc 层级，以及 API 应在的窗口。调试控件可接在现有模拟顶层；不要因多套一层容器而改变 `top`／`parent` 的含义。缺桥或接口放错层时，应能观察到失败，不能向每一层塞全局函数掩盖问题。
3. **确认测试数据。** 初始预设、后续注入、快照恢复和场景重置都先展示来源、批次、目标聊天／楼层、字段前后差异及预计事件，再明确确认。确认可通过项目界面或可追溯的对话完成，不要求特定按钮。确认绑定数据内容、作用范围与状态版本；等待期间发生变化就作废旧预览。完整场景序列确认一次后按已确认步骤执行，出现冲突或失败就停。
4. **比较实际结果。** 并列保留注入前、待注入、实际提交后的状态，以及各模块实际观察的字段。界面显示通过项目字段映射核对，事件按实际发生顺序记录。取消不写入；提交或恢复失败保留真实错误和可读回的状态，不记成成功。
5. **手动调参并回落。** 用项目适合的控件调布局、字号、间距与皮肤；确认选中的效果后回落真实源码，移除临时覆盖，再用同一场景检查。导出记录交给构建和实机检查。

## 全量范围与能力缺口

“全量”指本次确认范围内全部模块、入口与能力。清单来自实际工程，不能把范围缩到碰巧显示成功的几项。页面打开只证明入口可访问。

| 状态 | 记录要求 |
| --- | --- |
| 已装载 | 真实入口和必要依赖已挂载，交互与字段对照另记结果 |
| 未接入／未装载 | 本次范围内尚未完成适配或挂载的模块与入口 |
| 暂不支持 | 缺少的接口或宿主能力、原因、后续检查位置 |
| 本次未测试 | 尚无操作或字段映射证据，不能计为通过 |
| 失败 | 实际错误、状态、复现步骤及修复后的复测结果 |

联合模拟还要检查共享状态、事件顺序、遮挡、样式污染、重复实例、重复订阅与存储串用。切聊天再返回时核对各模块的作用范围和监听清理。

## 手动调参、基线与结果回落

- 声明参数名称、作用模块、范围、步长和单位。滑条与精确数值输入共用真实组件参数入口或范围明确的 CSS 变量；显示当前值与基线值，提供单项／整组复位、预设、导出和重新载入。
- 已采用的范围内，UI 调参即时预览，每次拖动不用重复确认。业务数据仍走注入确认。验证 UI 操作没有写入业务状态；若发现越界，停止这条调参路径，记录实际状态并修复适配，不宣称自动回滚或绝对隔离。
- 支持按住查看基线、松开回到候选。并排对照时，同一源码版本建立两个隔离实例，分别使用状态、存储命名空间、事件总线和 UI 参数；两个标签页不代表 localStorage 自动隔离。
- 如需调试面板，应能移动、收起、隐藏与重新打开，适配桌面和窄屏。用户手动调整预览尺寸时，Agent 不主动改变该视口；自动尺寸检查使用单独测试窗口。
- 参数导出绑定源码版本与作用模块。版本不一致先核对差异与迁移，不改版本号绕过检查。临时样式覆盖明确称为候选；回落后移除调试覆盖与宿主补丁，从维护源码复测。

## 证据与交接

将源码清单、模拟范围、场景与数据来源、确认记录、状态差异、实际事件、UI 参数、复现步骤和未覆盖项保存到项目测试目录，提供 JSON／Markdown 记录。自动检查、浏览器操作、真实宿主、驾驶员体验分别列出。

沙盒浏览器通过只证明该版本源码在本次适配与数据下的表现。真实 SillyTavern、Tavern Helper、MVU、消息楼层、模型和设备行为交给 `sillytavern-runtime-debug`，以准确的构建产物复验；`driverAccepted` 只能由驾驶员明确给出。

公开资料只放合成场景和脱敏机制。私有作品、原聊天、玩家数据与原始日志保留在项目工作区；需要分享复现时先审查最小材料。
