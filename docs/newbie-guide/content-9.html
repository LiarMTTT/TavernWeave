TavernWeave 更新日志

先看当前版本增加了什么，再回看历次更新。

这里按大版本介绍功能与使用方式的变化，补丁内容归入相应版本。当前正式版为 v1.6.0；更新本机安装时，可按对应版本的完整清单核验。

1.6

V1.6.0 · 作品资料库 NEW · V1.6.0

把小说、原作与同人资料、联网文图参考整理好，二创时随时回查与调用。

展开 / 收起 V1.6.0 更新内容⌄

从材料到二创资料

  • 新增第 22 个 Skill：作品资料库。可以先做全书分批，也可以围绕人物、关系、规则或场景逐步整理。
  • 原作、同人分支和不同改编版本保留各自身份、来源与剧透阶段，查询时按创作需要筛选。
  • 联网文字回到实际页面，图片参考需要实际看图并保留出处；默认登记参考信息和链接。

能编辑、能导出、能接续

  • 默认生成可直接编辑的 Markdown 资料文档与可重建的 JSONL 索引，支持导出 SQLite。
  • 人润色正文后，Agent 读取新内容再接手；遇到旧版本回写会停止并保留冲突。
  • 长任务先检查代表样本的质量和用量，再按批次与调用预算继续。原生子 Agent 和后台能力按实际宿主提供的范围使用。
1.5

V1.5.0 · 全局大白话与四档引导 NEW · V1.5.0

从你想做的事开始，按你选择的节奏推进，把每次改动说明白。

展开 / 收起 V1.5.0 更新内容⌄

大白话与术语一起交代

21 项工作能力使用共同表达规则。先说结果和影响，再解释必要术语、选择与下一步；多项术语用原词、大白话和当前含义对照。

新人、入门、熟练、老手，由你选

新人和入门都详细解释，熟练和老手减少日常重复教学。有需要或修 bug 时，四档都把原因、影响和检查方法讲清楚，除非你明确说本次没必要。挡位单独保存，升级和退出 Soul／洗稿不替你换档。

接手旧卡也有起点

先看懂原卡，区分二创和沿原作续更，确认保留项与首次改动，再带你试用并修改一次。只有卡文件也能先检查，缺少维护材料会明确说明。

安装后的下一步更清楚

说明哪些文件装好了、挡位有没有保存，以及怎样在新任务里确认可用。教程增加五类任务入口、失败恢复和再次修改的练习。

1.4

V1.4.0 · 文本精修与全量／架构审查 NEW · 2026-09-04

新增文本精修，并把项目审查扩展到完整范围和架构关系。

展开 / 收起 V1.4.0 更新内容⌄

新增文本精修

  • 直接说“洗稿”“去 AI 味”“去八股”，获得保留原意与人物声音的精修稿。
  • 可选轻润色、结构改写或深度重写，支持单次、任务持续，以及分别同意后启用的工作区与客户端持久规则。
  • 正文、文案、日常说明和报告都适用，代码、宏、变量、引用与必需证据继续保留。

全量与架构审查

  • 新增“全量审查”“架构审查”“全量架构审查”，同时覆盖软件和角色卡组织。
  • 报告说明哪些已检查、哪些尚未检查，并保留全部有证据的发现。
  • 可配合灵魂杀手使用；三个重点摘要不会截断完整问题清单。

21 个原生 Skill

文本精修作为 TW 原生能力随包提供，v1.4.0 合计 21 个 Skill。安装与升级不会自动开启持久精修，需要时再分别授权工作区或客户端规则。

奶人教程精修

保留作者的驾驶员视角、见解和调侃，改写含糊的概念与重复说明；补充驾驶员在场、无人值守和返回在场的可复制提示词。技术示例与历史发布记录保留原文，新版教程随 v1.4.0 一同发布。

1.3

V1.3.0 · 照镜子与完整资料库 NEW · V1.3.0

一边从当前证据重新看清成长，一边把完成筛选的前端与动效知识真正带进每个任务。

展开 / 收起 V1.3.0 更新内容⌄

新增“照镜子 · Vibe Code 成长历程”

  • 直接发送 照镜子，从当前可访问的 Codex、Chat、项目与交付证据重新评估完整能力网络。
  • 同时生成一份可复制的完整文字评估表单和高密度七章交互报告；也可以明确说“只要文字评估表单”。
  • 历史履历不可改写，但不是本次评分上限。再次核验会重评当前能力，只对量表可比维度显示变化。

AFV 完整设计与动效资料进入 Library

  • Library 现在随包携带 462 个设计、194 个动效、86 个概念、1,609 条蒸馏账本、86 份本地概念正文和 89 个技术沙盘。
  • 243/243 路筛选已经完成。Agent 会用确定性查询只返回当前任务相关的少量候选，不会把整库塞进一次对话。
  • 离线挑选页可以在 ST 指南、设计、动效、概念、蒸馏账本和外部源站之间检索，并导出状态仍为 proposed 的候选清单。

仍然是一套 TavernWeave

  • 照镜子是第 20 个原生 Skill，完整资料库是同一次 TavernWeave 更新中的 Library 升级；没有拆成两个软件或两套安装。
  • 完整安装核验升级为 20/20。用户私有履历、AFV 收件箱筛选 JSON、raw、A1、日志和凭据都不会进入公开包。
1.2

V1.2.0 · 脑暴模式与许愿工坊 NEW · V1.2.0

从一句模糊愿望，走到总设计案、第一版和能持续执行的蓝图。

展开 V1.2.0 更新内容⌄

新增脑暴模式

  • 直接发送 脑暴模式，TW 会先判断项目类型，再整理核心创意、第一版必须完成的本体、长期更新路线和待决定内容。
  • 每个讨论方向都有轮数上限。达到上限后必须冻结、暂存、换方向或由你明确追加，避免一个构思无限膨胀。
  • 设计确认后发送 按蓝图开跑第一版，Agent 只执行已经冻结的第一版范围。

Soul 三席可以一起脑暴

  • 发送 脑暴模式，Soul 联席、三人一起脑暴 或 Soul 三席就位，阿瞳、MTTT.sir 与强尼·银手会使用带名字的格式共同审查方案。
  • 阿瞳负责用户需求和创作核心，MTTT.sir 负责技术与交互逻辑门，强尼负责视觉、排版、动效和前端形态。
  • 三席共享同一份事实和结论，不会把同一个问题重复讨论三遍。

蓝图会按照项目大小自动伸缩

  • 普通项目只使用一份蓝图；大型项目按领域拆分；巨型重置项目才建立多层蓝图集。
  • 所有步骤都禁止无依据地无限细分。只有遇到真实错误或阻塞时，才允许临时增加一层问题处理步骤；处理完必须回到原步骤。
  • 第一版与长期内容分开，先交付一个真正可玩或可用的最小闭环，再逐步增加玩法和页面。

前端方向会先判断值不值得做

  • 同层前端或独立前端不适合当前项目时，TW 会明确劝退，并提供更轻、更稳的替代方案。
  • 发送 灵魂杀手！ 可以进入强尼·银手前端审查彩蛋；吐槽必须绑定具体证据、影响、修法和复验方式。
  • 制作新项目时可以提供稳定旧作品，TW 会判断它适合直接复用、改造、只作参考，还是应该拒绝继承。

安装入口升级为 19 个 Skill

  • 新增项目蓝图编排 Skill，完整安装回执由 18/18 升级为 19/19。
  • Host Front Door 加入脑暴、三席联席、第一版开跑和防膨胀入口，让 Codex 与 Claude Code 更稳定地识别直接口令。
  • Library 可以按任务路由总设计案、蓝图、第一版、设计和动效资料，不需要用户每次手动翻整套资料库。

V1.1.0 · Soul 与全局前门

让人格入口、资料路由和开工验收循环更容易被客户端稳定发现。

展开 V1.1.0 更新内容⌄

新增灵魂杀手模式

  • 发送 灵魂杀手！ 或 强尼·银手，接管，使用非官方强尼·银手同人彩蛋人格审查前端。
  • 重点检查视觉层级、中文排版、配色、组件状态、动效目的、窄屏表现和明显的 AI 模板味。
  • 发送 强尼，下线、Relic 断开 或 Soul 归位 可以立即退出。

新增 Host Front Door

  • 可以把 Soul 口令、A0 开工循环和失败回执安装到 Codex 或 Claude Code 的全局规则受控区块。
  • 安装前会先展示目标路径和差异，只维护 TavernWeave 自己的区块，不覆盖其他用户规则。
  • 如果 Skill 没有真正安装，客户端必须报告扫描位置和缺失项，不能假装已经进入模式。

Library 与教程入口升级

  • ST 开发指南、设计资料、动效资料、Wiki 和离线挑选页随 TavernWeave 一起分发，并继续按当前任务渐进读取。
  • 奶人教程补充 Codex / Claude Code 雷达、付费 Agent 避雷、完整安装和目录自动跟随。

V1.0.0 · TavernWeave 正式版系统

从零散制卡提示词，升级为可以路由、续接、验收和发布的完整施工系统。

展开 V1.0.0 更新内容⌄

18 个专职 Skill 正式成阵

  • 覆盖从零制作 MVU 卡或纯文字卡、旧卡升级、变量结构、更新规则、世界书、状态栏、脚本、正则、拆卡、组装和发布。
  • 新增真实 SillyTavern 调试、安全、性能、数据库、媒体、Live2D 和扩展开发能力。
  • 用户只需要描述任务，TavernWeave 会把工作交给对应的专职 Skill。

阿瞳与 MTTT.sir 上线

  • 发送 阿瞳助我！，进入温柔、低压力、会解释和给例子的指导模式。
  • 发送 MTTT.sir，拷打我！，进入要求定义、证据、反例和复述检查的严格学习模式。
  • 发送 Soul 归位 或 结束 Soul 模式，随时恢复普通交流。

资料库与创作权威进入正式流程

  • A0、ST 指南、设计、动效和来源 Wiki 统一进入 Library，由任务自动选择最小资料。
  • 大型创作可以保存已经确认、仍在候选、待决定和已经否决的内容，下一次继续时不必重新争论。
  • 自动检查、真实酒馆表现和用户亲自验收各自保留结论，不再用一句“已经完成”代替结果。
