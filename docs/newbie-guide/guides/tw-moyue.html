1. 三分钟上手：五条铁律 + 贴身模板

铁律内容
铁律 1开工先报主干。TavernWeave 的 22 个 skill 和墨月的 9 个都监听「角色卡 / 世界书 / MVU / 状态栏」。不共根之后撞车概率低了，但装在用户级的 TW skill 在墨月文件夹里照样看得见。在哪个文件夹开工，第一句话都发「项目主干声明」（模板见 §8）。
铁律 2一项目一事实来源。A 主干记「创作权威」文档；B 主干记 src/<卡名>/项目状态.md ＋ index.yaml，创作台.md 是你自己的原文，秋青子只读不改（moyu-project/SKILL.md 第 35 行）。同一张卡绝不双记账。
铁律 3验收只能你亲口说。TW 的 driver-accepted、墨月的酒馆实测，都只能由你说出。墨月自己在 moyu-package/SKILL.md 第 13 行写明：打包成功只说明结构能生成，酒馆运行、模型效果、视觉效果都还没过。
铁律 4墨月整包用，不拆。它的 9 个 skill 是薄路由（每个 19–36 行），全靠 ../../../ 往上读 知识库/、必读/、@types/、初始模板/，9 个文件共 24 处；调用顺序由根层入口 → 必读/02_专项路由.md 决定；4 个脚本写死 src/<卡名>/ 与 tavern_sync.yaml。把 moyu-* 拷进别的目录，24 条路径全断，作者本人也提醒过这一点。要用它，让它自己的文件夹当根。
铁律 5两条主干不共根。TavernWeave 工作区是一个文件夹，墨月工坊是另一个。跨界只有两条只读的路：① TW 的审计 skill 装到宿主的用户级目录，去看墨月的卡；② TW 主干的卡按路由表点名读墨月知识库，读的是一份入口已移出的参考副本（§10.7），主干那份另放。

贴身模板（墨月主干版；TavernWeave 主干版见 §8）

你说【项目主干声明】本项目《XX》： 1) 主干：墨月本地写卡工坊（秋青子 → moyu-project 排序 → 各专项 → moyu-package 打包）。工作根：本文件夹。 2) 唯一事实来源：src/XX/项目状态.md 与 index.yaml。创作台.md 是我的原文，只读。 3) TavernWeave 只允许使用：sillytavern-rolecard-security / rolecard-performance / api-reference 只读审计与查证，并读取必需的 consult-tavernweave-library；不改任何文件。 4) 顺序、确认点、目录布局、构建与打包全部按墨月自己的来；不引入 TavernWeave 的创作权威、总设计案、蓝图、cards/ 目录。 5) 禁止：用 TavernWeave 的 tavern-card-builder / card-components / card-pipeline / embedded-ui 改写或重打包本项目；维护第二份状态文件。 6) 每进入一个新专项前，先复述你对我需求的理解和本专项的确认点，等我确认再写正式文件。

3. 开局判定：这张卡走哪条主干

两条主干都能做人物、世界书、MVU、前端、打包，功能上分不出高下。分叉点在驾驭体验：你想自己指挥每一道门、看证据逐层递交，还是想大白话进、让秋青子替你拆专项、少被问技术选型。

10.6 墨月在 Claude Code 上的入口壳（改入口，不改 skill）

墨月自带三个入口文件：AGENTS.md（约 6.7 KB，正文）和 CLAUDE.md / GEMINI.md（各 255 字节、内容相同，是一段指针：让模型先完整读 AGENTS.md，并声明 AGENTS.md 是唯一规则源）。Claude Code 打开墨月文件夹时会自动加载这份 CLAUDE.md。要加的只有一个：Claude Code 在本机观察里不扫描 .agents/skills，得给它一个 .claude/skills 软链。

# 撤：rm -r .claude   —— 回到原包
三个已知点
  • 自带的 CLAUDE.md 指针是一段散文，没有用 @AGENTS.md 导入语法。Claude Code 会加载这 255 字节，但接下来去不去读 AGENTS.md 是模型自己的选择。第一次开会话若秋青子没出现，在第一句里明说「先完整读根目录 AGENTS.md」，并记进 §9。CLAUDE.md 是原文件，保持原样。
  • macOS 自带 unzip 在非 UTF-8 locale 下会把中文文件名解坏（一个目录都建不出来）。用 Python 的 zipfile 或其他按 zip 内 UTF-8 标记解压的工具。装依赖用 pnpm（包内有 pnpm-lock.yaml 与 pnpm-workspace.yaml）；没装 pnpm 可用 corepack pnpm install --frozen-lockfile，然后 corepack pnpm run check:workshop。
  • Windows 上软链需要开发者模式或管理员权限；不行就把 .agents/skills 复制一份到 .claude/skills（成了两份文件，墨月更新时记得同步）。
这一节的壳与墨月自检（check:workshop）已在一台 macOS 上跑通：263 个原文件逐个 CRC 与原包一致，只多 .claude/skills 与 node_modules/。秋青子是否随之出现仍是 §10.4 效果第 10 条，未测。
