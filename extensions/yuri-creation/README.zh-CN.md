# Yuri Card Creator 0.2.0（原创百合制卡扩展）

只通过对话制作原创百合角色卡。未指定的细节由智能体决定，开场、世界书和可导入 SillyTavern 的 JSON 文件也由它处理。

## 开始使用

用能够读写文件的智能体打开本文件夹，然后说：

```text
使用 yuri-card-creator，帮我创作一张原创百合角色卡。
没有指定的细节由你决定，先给我一个完整初稿。
复用我保存的偏好，文件由你处理；我会直接在对话中反馈。
```

不需要提供原文、参考资料或图片。初始主要角色均为成年女性，包括作者定义的虚拟及非人女性。玩家当下的动作、内心和回答仍由玩家决定。

完成后会得到最终角色卡、世界书和原创记录。把最终 JSON 或使用选定头像打包的 PNG 导入 SillyTavern，再在对话中提出修改意见即可。世界书已内嵌在角色卡中。

## 当前内容

- 一个原创制卡技能：核心指令英文，用户交互支持中文和英文。
- 沿用三个已保存的百合偏好，不要求重新填写问卷。
- 一个轻量构建助手，以及保留 MIT 许可和署名的 Foreverse 原版导出工具。
- 可选的 TavernWeave 固定版本写作文件校验；未提供基础项目时也可明确以独立模式创作。

这是便携项目检查点，尚非特定宿主的原生插件。原生宿主安装不包含在本扩展中；可选图片操作使用当前工作区已有工具。

许可边界见 [LICENSE_BOUNDARY.md](LICENSE_BOUNDARY.md)，集成说明见 [INTEGRATION.md](INTEGRATION.md)。本扩展的新编写文件使用此目录中的 MIT 许可证；仓库根目录的上游许可证及各组件原有条款保持独立。

## 可选功能

可以直接让 Agent 联网核对背景、查看图片是否符合角色设定，或将选好的 PNG 头像打包成角色卡。联网和图片生成、编辑使用当前工作区已有的工具；没有这些工具也能完成文字卡。PNG 打包保留图像数据，不会自动重绘。

当前仅提供成年女性主角的默认创作路径。自定义偏好模式的完整兼容暂缓处理；保存了偏好文件不等于所有选项都已经生效。原生宿主安装不包含在本扩展中。
