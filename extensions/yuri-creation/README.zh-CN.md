# Yuri Card Workbench 1.0.0（百合制卡扩展）

通过对话创作百合角色卡、改编已有角色卡，或把帖子和小说片段变成新的故事。文件由智能体处理，你直接在对话里审阅和修改。

[English](README.md)

## 各宿主安装

| 宿主 | 分发分支 | 安装方式 |
| --- | --- | --- |
| Codex / ChatGPT Work | `yuri-plugin` | 导入并启用 `tavernweave-yuri` 插件 |
| DeepSeek Harness | `DSH-plugin` 或正式版 `.tgz` | 安装 DSH 包，选择 Yuri Workbench 预设 |
| Gemini CLI | `main` 或 `Gemini-plugin` | 安装完整扩展，自动发现技能 |
| Gemini Task 模式 | `Gemini-plugin` | 分别导入四个技能，保留完整共享目录 |

Gemini CLI 已通过扩展导入及技能识别测试，无须逐项导入；Task 模式仍采用单独导入方式。Agent 按任务加载对应工作流和依赖。安装命令及更新方法见[安装说明](docs/NATIVE_HOSTS.md)。


## 从哪里开始

用能读写文件的智能体打开本文件夹，提供材料，再选择一种说法：

| 你手里的材料 | 可以这样说 |
| --- | --- |
| 一个想法，或者还没有想法 | “帮我创作一张原创百合角色卡。没有指定的细节由你决定，先给我完整初稿。” |
| 已有 JSON 或 PNG 角色卡 | “把这张卡改编成百合故事，保留原图、脚本及无关的世界书设置。” |
| 一段帖子 | “把这段帖子改编成百合角色卡，发帖人的位置设为 {{user}}，原文事实与新创作分开记录。” |
| TXT、Markdown 或 EPUB 小说 | “用这一章或场景制作百合角色卡；如果我还没指定范围，先选一个较短章节。” |

让智能体阅读本文件夹中对应的工作流即可，不需要你手动填写 Markdown 或 JSON 表格。文件夹里若有多张卡、多个版本或拆分组件，它会先识别各自归属，再进行修改。

## 审阅与导入

智能体会展示人物、可游玩的开场和世界书。你直接在对话中提出意见即可。默认主要角色为成年女性，包括作者定义的虚拟及非人女性；背景人物身份保持原样。玩家当下的动作、内心和回答仍由玩家决定。

现在可以在对话中调整人物范围、排除个别人、保留关系结局、指定配对或自定义判定标准。智能体负责保存和检查偏好；不支持的选项会明确说明。具体范围见[自定义偏好](references/custom-profiles.md)。

如果沿用的名字与人物设定不太协调，智能体会说明原因并提出备选名。你可以选新名字，也可以保留原名；不会仅因名字听起来偏男性就自动改名。

选择换图后，智能体会观察原图的画风、笔触、配色和构图，结合改编卡的叙事气质编写绘图提示，并把原图作为实际参考交给可用绘图工具。生成后先查看候选图，再交给你审阅，确认后才嵌入；原图保留。参见[图片改编](references/image-adaptation.md)。

将最终 JSON 或角色卡 PNG 导入 SillyTavern，世界书已经内嵌。智能体会指出最终应使用的文件，并把原文记录、改编说明单独保存。修改旧卡时保留原始文件，不改动无关字段、代码及世界书加载设置。

长篇小说不必一次塞进一条消息。可以指定章节或明确的片段范围，保留来源记录，分阶段继续。不会悄悄截断输入，也不会声称已经读过未选中的章节。

## 文件夹里有什么

| 工作流 | 用途 |
| --- | --- |
| yuri-card-creator | 不依赖参考资料的原创制卡 |
| adapt-yuri-card | 在保护无关内容的前提下修改 JSON/PNG 旧卡及世界书 |
| post-to-yuri-card | 从提供的帖子改编 |
| novel-excerpt-to-yuri-card | 从指定 TXT/Markdown/EPUB 小说片段改编 |

联网、图片查看和可选绘图使用当前智能体已有工具；没有图片也能完成文字卡。原生包提供这些工作流的发现入口，账号安装及工具权限仍取决于当前宿主。保护编辑保留原有结构；结构迁移或脚本修改需要单独明确范围。纯文本或 DOCS 拆分组件使用宿主读取、导出及上游写作流程，不冒充无损 JSON 往返编辑。
