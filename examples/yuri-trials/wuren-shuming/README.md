# 《无人署名》创作测试

本目录保存用户通过审阅的原创中文现实主义悬疑百合角色卡。`source/` 是可由 `extensions/yuri-creation/skills/yuri-card-creator` 重新构建的创作源；`result/` 包含 SillyTavern v2 JSON、内嵌世界书的独立副本及生成记录。用户提供的散文评论用于主题启发，不作为经证实的史实或外部检索来源；不包含评论全文。文中地点和人物为虚构。

开场中的一次“你”改为 `{{user}}` 以符合导出器要求；正文组织为导出器支持的字段。已检查角色卡结构、十条世界书与四组对话；用户已反馈 PNG 导入正常，并对一轮短对话表示满意；维护者已审阅私密对话导出，但未操作用户的酒馆界面。私密聊天记录和 PNG 图像不在本目录中。可导入 `result/yuri-card.v2.json`，无需重复导入独立世界书。

本目录为一次测试的内容，不修改扩展的发行清单。后续如要纳入正式发布，应由维护者确认内容授权、文件位置与许可。
